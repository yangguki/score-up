# SCORE UP 종목 룰 명세서

| 항목 | 내용 |
| --- | --- |
| 문서명 | 종목 룰 명세서 |
| 버전 | v0.2 |
| 기준 문서 | SCORE-UP 기획서 v0.2 |
| 대상 종목 | 농구, 배구, 탁구 |
| 목적 | 스코어보드 버튼, 상태 전이, 종료 조건, 제재를 구현 가능한 수준으로 고정한다 |
| 수정일 | 2026-08-21 |

v0.2: 농구 시계는 보드의 경기 시작으로만 돈다. 작전타임 전용 시계·시간 설정. 쿼터 수는 최소 2.

이 문서는 공식 연맹 룰북을 그대로 옮긴 것이 아니다. **생활체육/동호회 현장에서 경기를 운영하기 위한 프리셋**이다. 공식 값과 자주 쓰는 변형 값을 함께 적는다.

## 1. 공통 룰 엔진

모든 종목은 같은 경기 상태와 이벤트 로그 위에 올라간다. 종목 차이는 **어떤 버튼을 보여줄지**, **언제 세트/경기를 끝낼지**, **제재가 출전에 영향을 주는지**다.

### 1.1 경기 상태

| 상태 | 의미 | 기록 가능 |
| --- | --- | --- |
| `scheduled` | 대진에 배정됨. 아직 로스터 확정 전 | 아니오 |
| `lineup` | 출전 명단 확인 중 | 로스터만 |
| `in_progress` | 진행 중 | 예 |
| `period_break` | 쿼터/세트/전후반 사이 | 제한적 (정정, 로스터) |
| `paused` | 운영자가 일시정지 | 아니오 (재개 전) |
| `confirm_period_end` | 시스템이 단위 종료를 제안 | 종료 확정/취소만 |
| `confirm_match_end` | 시스템이 경기 종료를 제안 | 종료 확정/취소만 |
| `completed` | 결과 확정 | 관리자 정정만 |
| `forfeited` | 몰수/기권 | 아니오 |
| `abandoned` | 중단 후 미재개 | 아니오 |

원칙: **시스템이 제안하고, 운영자가 확정한다.** 점수가 종료 조건에 닿아도 바로 잠그지 않고 `confirm_*` 상태로 올린다. 오터치 여유를 남기기 위해서다.

### 1.2 공통 이벤트

| 이벤트 | 공통 필드 | 종목 payload 예시 |
| --- | --- | --- |
| `point` | 팀, 선수(선택), 시각 | `{ points: 2 }`, `{ points: 1 }` |
| `foul` | 팀, 선수, 시각 | `{ personal: true, team: true }` |
| `timeout` | 팀, 시각 | `{ remaining: 1 }` |
| `substitution` | 팀, in, out | — |
| `serve_change` | 팀 | 배구/탁구 |
| `period_end` | 종료된 단위 | `{ quarter: 2 }`, `{ set: 1 }` |
| `match_end` | 승자 | `{ reason: "score" \| "forfeit" }` |
| `revoke` | 원 이벤트 id | — |

현재 스코어는 숫자만 저장하지 않는다. **이벤트 로그를 다시 재생해 계산**한다. 정정은 마지막 이벤트를 지우는 것이 기본이고, 과거 이벤트는 `revoke`로 무효화한다.

### 1.3 공통 조작

| 액션 | 동작 |
| --- | --- |
| 실행 취소 | 가장 최근 유효 이벤트를 revoke |
| 일시정지 / 재개 | `paused` ↔ `in_progress`. 타이머가 있는 종목은 시계도 멈춤 |
| 몰수 / 기권 | 상대 승, 종목별 기본 스코어로 기록 (아래 종목 절 참고) |
| 중단 | `abandoned`. 대진에는 “중단”으로 남고 관리자가 재배정 |
| 결과 확정 | `completed`. 이후 대진/순위에 반영. 수정은 관리자만 |

### 1.4 룰 변경 시점

- 대회 생성 시: 이 대회의 적용 룰을 저장한다
- 경기 시작 전: 관리자만 예외적으로 수정 가능. 수정하면 해당 경기에만 적용
- 경기 시작 후: 룰 값 변경 금지. 오입력이면 이벤트를 정정한다

## 2. 농구

시간제 + 누적 득점 + 개인/팀 파울을 검증하는 종목이다.

### 2.1 프리셋 값

| 항목 | 공식 기본값 (FIBA 감각) | 동호회 기본값 (SCORE UP 1차) | 커스텀 범위 |
| --- | --- | --- | --- |
| 진행 단위 | 4쿼터 | 4쿼터 | 최소 2쿼터, 최대 4쿼터 (2 / 3 / 4) |
| 쿼터 시간 | 10분 | 8분 | 4 / 6 / 8 / 10 / 12분 |
| 연장 | 5분, 승부 날 때까지 | 3분, 최대 2회 후 자유투 승부(선택) | 연장 없음 / 무제한 |
| 득점 단위 | 1 / 2 / 3 | 1 / 2 / 3 | 고정 |
| 개인 파울 아웃 | 5 | 6 | 4~8, 또는 제한 없음 |
| 팀 파울 보너스 | 쿼터 5번째부터 보너스 | 쿼터 5번째부터 보너스 | 4~8, 또는 사용 안 함 |
| 타임아웃 횟수 | 하프별 제한 | 팀당 경기 2회 | 0~5 |
| 작전타임 시간 | 60초 | 60초 | 30 / 45 / 60 / 90초 |
| 샷클락 | 24초 | MVP에서 없음 | Phase 2 |
| 출전 인원 | 5 | 5 | 3x3는 이후 종목 |

1차 동호회 기본값을 앱의 기본 프리셋으로 둔다. 공식 값을 고르면 위 왼쪽 컬럼으로 바뀐다.

### 2.2 상태와 화면 표시

경기 화면에 항상 보이는 것:

- 홈/어웨이 총점
- 현재 쿼터 (`Q1`~`Q4`, `OT1`…)
- 남은 시간
- 팀 파울 (이번 쿼터)
- 최근 이벤트 1~3개
- 작전타임 중이면 중앙에 작전타임 남은 시간

선수 선택 후에 보이는 것:

- 해당 선수 개인 파울
- 출전 중 여부

### 2.3 득점

| 버튼 | 점수 | 선수 지정 | 비고 |
| --- | --- | --- | --- |
| +2 | 2 | 권장 | 가장 많이 누른다. 선수 없이 팀 득점도 허용 |
| +3 | 3 | 권장 | |
| +1 | 1 | 권장 | 자유투. 보너스 상황에서 강조 표시 |
| 취소 | — | — | 직전 득점 revoke |

선수 지정 흐름 (권장):

1. 왼쪽/오른쪽 팀의 득점 버튼을 누른다
2. 출전 중인 선수 목록이 뜬다
3. 선수를 고르면 이벤트가 확정된다
4. “팀 득점”을 누르면 선수 없이 기록한다 (동호회에서 자주 필요)

빠른 입력 흐름 (토글):

- 선수 선택 없이 바로 팀 점수에 더한다
- 나중에 타임라인에서 선수를 붙일 수 있다

### 2.4 타이머

| 동작 | 규칙 |
| --- | --- |
| 출전 확정 | 상태 `in_progress`. 시계는 정지 (`started: false`). 득점·파울·T/O 잠금 |
| 경기 시작 | 보드의 **경기 시작**. 1쿼터 시계 시작, `started: true` |
| 일시정지 | 경기 시계 정지. 파울/자유투에 운영자가 누른다 |
| 재개 | 정지된 경기 시계를 다시 돌린다 |
| 쿼터 종료 | 0:00이 되면 `confirm_period_end`. 추가 득점 입력은 막고 정정만 허용 |
| 다음 쿼터 | 운영자 확정 시 팀 파울 0으로 리셋, 시계 재장전. **다음 쿼터 시작**을 눌러야 시계가 돈다 |
| 하프 | Q2 종료 후 휴식 화면. 기본 휴식 시간은 기록만, 강제하지 않음 |
| 마지막 쿼터 종료 | 동점이 아니면 `confirm_match_end`. 동점이면 연장 진입 제안 |

타이머가 0이 되어도 직전 1~2초 입력은 정정으로 살릴 수 있다. 종료 확인 팝업에 “마지막 기록 취소”를 둔다.

### 2.5 파울

파울은 농구 모듈의 핵심이다. 메모가 아니라 **출전과 보너스를 바꾼다.**

| 종류 | 기록 | 효과 |
| --- | --- | --- |
| 개인 파울 | 선수 +1, 이번 쿼터 팀 파울 +1 | 제한 도달 시 해당 선수 출전 불가 |
| 팀 파울 | 쿼터 단위 누적 | 보너스 기준 도달 시 상대 +1 버튼을 강조 |
| 기술/언스포츠 (간단) | 개인 파울로 취급 | MVP에서는 유형 구분만 하고 효과는 동일 |
| 공격자 파울 | 개인 + 팀 파울 | 득점은 없음. 보너스 계산에는 포함할지 대회 룰로 선택 (기본: 포함) |

**파울 아웃**

- 개인 파울이 제한(기본 6)에 도달하면 알림: “12번 파울 아웃”
- 해당 선수는 교체 out 처리되고, 다시 in 할 수 없다
- 이미 5명만 남아 있으면 경고만 하고, 운영자가 속행 여부를 고른다 (동호회 현실)

**보너스**

- 이번 쿼터 팀 파울이 기준(기본 5) 이상이면 상대 팀 측에 “보너스” 표시
- 자유투(+1) 버튼을 크게 보여 준다
- 보너스는 힌트다. 실제 자유투 성공/실패는 운영자가 +1을 눌러 기록한다
- 자동으로 +1을 넣지 않는다

### 2.6 교체 · 타임아웃

| 기능 | MVP 규칙 |
| --- | --- |
| 교체 | 횟수 제한 없음. 출전 5명 유지가 기본. 3명 미만이면 시작/재개 불가 |
| 파울 아웃 선수 | 교체 목록에서 비활성 |
| 타임아웃 | 팀 버튼. 남은 횟수 0이면 비활성. 경기 시작 전에는 잠금 |
| 작전타임 시계 | T/O 시 경기 시계 정지, 화면에 `timeoutSeconds` 카운트다운. 끝나면 `paused`. 재개로 경기 시계를 다시 돌린다. 중간에 타임아웃 종료 가능 |

### 2.7 종료 조건

```text
쿼터 시계 = 0
  → 마지막 쿼터/연장이 아니면 쿼터 종료 확인
  → 마지막 단위이고 점수 불일치면 경기 종료 확인
  → 마지막 단위이고 동점이면
        연장 허용 시 OT 시작 제안
        연장 없음이면 무승부 확정 (리그) 또는 연장 강제 (토너먼트)
```

토너먼트 경기는 무승부를 허용하지 않는다. 연장 없음으로 설정된 토너먼트는 앱이 “연장을 켜라”고 대회 생성 단계에서 막는다.

**몰수 스코어:** 기본 `20-0`. 대회에서 변경 가능.

### 2.8 스코어보드 버튼 배치

태블릿 가로 기준.

```text
[홈 팀명]          Q2  05:32          [어웨이 팀명]
  24              팀파울 3 - 4              18
                 보너스     ·

[ +2 ] [ +3 ] [ +1 ]                 [ +1 ] [ +3 ] [ +2 ]
[ 파울 ] [ 교체 ]                     [ 교체 ] [ 파울 ]
[ 타임아웃 1/2 ]                       [ 타임아웃 2/2 ]

최근: 12번 +2 · 5번 파울(3) · 홈 타임아웃
[ 실행취소 ]  [ 일시정지 / 재개 / 경기 시작 ]

작전타임 중 중앙 오버레이: 팀명 + 남은 초 + [ 타임아웃 종료 ]
```

- 득점 버튼은 양쪽에 대칭으로 둔다. 기록원이 어느 쪽 벤치에 앉아도 가까운 팀을 누르게
- 파울은 득점보다 한 단계 작게, 실수 입력을 줄인다
- `쿼터 종료`는 시계가 0이 되면 강조. 그 전에는 수동 종료(시계 고장 대비)로 숨김 메뉴에 둔다
- 보드에 처음 들어오면 하단은 **경기 시작**. 시계가 돈 뒤에는 일시정지/재개

### 2.9 알림

| 조건 | 메시지 | 강제 |
| --- | --- | --- |
| 개인 파울 = 제한-1 | “다음 파울 시 아웃” | 아니오 |
| 개인 파울 = 제한 | “파울 아웃. 교체하세요” | 출전 재진입 차단 |
| 팀 파울 = 보너스 기준 | “보너스 상황” | 아니오 |
| 시계 0 | “쿼터 종료를 확정할까요?” | 확정 전까지 득점 잠금 |
| 4쿼터 종료 + 동점 | “연장으로 갈까요?” | 토너먼트는 예만 가능 |
| 타임아웃 0 | 버튼 비활성 | 예 |
| 작전타임 진행 | 중앙에 남은 초 표시 | 경기 시계·득점 잠금 |

### 2.10 MVP에서 하지 않는 것

- 샷클락, 8초 바이올레이션
- 자유투 시도/성공을 별도 스탯으로 자동 계산 ( +1 기록만)
- 리바운드, 어시스트, 스틸
- 3x3 룰
- 파울 유형별 상이한 페널티 자동화

## 3. 배구

세트제 + 목표 점수 + 서브권을 검증하는 종목이다. 시계는 없다.

### 3.1 프리셋 값

| 항목 | 공식 기본값 | 동호회 기본값 (1차) | 커스텀 범위 |
| --- | --- | --- | --- |
| 경기 형식 | 5판 3선승 | 3판 2선승 | 1세트 / 3판 2선 / 5판 3선 |
| 일반 세트 점수 | 25 | 25 | 15 / 21 / 25 |
| 마지막 세트 점수 | 15 | 15 | 11 / 15 / 21 |
| 승점 차 | 2점 차 | 2점 차 | 1점 차(시간 부족 대회) / 2점 차 |
| 상한 점수 | 없음 (2점 차까지) | 없음 | 27점 상한 등 선택 |
| 서브 | 랠리 포인트, 득점 팀이 서브 | 동일 | 고정 |
| 로테이션 | 공식 로테이션 | 사용 안 함 (선택 켜기) | on/off |
| 타임아웃 | 세트당 팀 2회 | 세트당 팀 1회 | 0~2 |
| 출전 인원 | 6 | 6 | 4~6 (레크레이션) |

### 3.2 상태와 화면 표시

항상 보이는 것:

- 현재 세트 점수 (홈-어웨이)
- 세트 스코어 (예: 1-0)
- 각 세트 점수 이력 (25-20, 23-25 …)
- 서브권 (어느 팀이 서브하는지)
- 최근 이벤트

로테이션을 켠 경우에만:

- 현재 전열 위치 (간단 번호). MVP는 위치 검증까지 하지 않고 표시만 한다

### 3.3 득점

배구의 기본 버튼은 **+1 하나**다.

| 버튼 | 동작 |
| --- | --- |
| 홈 +1 | 홈 세트 점수 +1. 홈이 서브권이 아니었으면 서브권 홈으로 이동 |
| 어웨이 +1 | 대칭 |
| 서브 변경 | 점수 없이 서브권만 고침 (오기록 대비) |
| 실행 취소 | 직전 득점과 서브권 변화를 함께 되돌림 |

득점 시 선수 지정은 선택이다. 켜면 “공격 득점 선수”를 고를 수 있으나, MVP 기본은 팀 득점만으로 경기를 끝낼 수 있게 한다.

### 3.4 세트 종료 조건

```text
한 팀 점수 >= 세트 목표
AND 점수 차 >= 필요 승점 차
AND (상한이 있으면 상한 도달 시 1점 차로도 종료)
  → confirm_period_end (세트 종료)
  → 세트 스코어 +1
  → 세트 승수 = 필요 승수 이면 confirm_match_end
  → 아니면 다음 세트 0-0, 서브권은 규칙대로 초기화
```

**듀스**

- 24-24 (25점 세트)가 되면 화면에 “듀스 · 2점 차”를 보여 준다
- 26-25처럼 1점 차면 세트를 끝내지 않는다
- 1점 차 커스텀 룰이면 목표 점수 도달 즉시 종료 제안

**마지막 세트**

- 목표 점수가 15(기본)로 바뀐다
- 14-14 듀스와 동일 로직

### 3.5 서브권

| 시점 | 동작 |
| --- | --- |
| 경기 시작 | 운영자가 선서브 팀을 고른다. 고르지 않으면 홈 기본 |
| 득점 | 득점 팀이 다음 서브를 가진다 |
| 세트 사이 | 다음 세트 선서브는 “이전 세트 선서브의 반대”가 기본. 변경 가능 |
| 오기록 | 서브 변경 버튼으로 점수 없이 교정 |

서브권은 화면에 반드시 보여야 한다. 배구에서 스코어만 있고 서브가 없으면 현장 사용이 어렵다.

### 3.6 제재 (MVP)

배구 공식 카드/퇴장은 Phase 2다. MVP에서는:

- 몰수 세트: 운영자가 “이 세트 몰수”를 고르면 상대가 목표 점수-0으로 세트를 가져간다
- 경기 몰수: 상대 세트 스코어를 필요 승수로 채운다 (예: 2-0)
- 경고 메모: 선수/팀에 텍스트 메모. 출전 제한은 없음

### 3.7 스코어보드 버튼 배치

```text
[홈]  ●서브                 SET 2                 [어웨이]
 16                    세트 1-0                     14
                 25-20 / 진행 중

[ +1 ]                                           [ +1 ]
[ 타임아웃 0/1 ]                                   [ 타임아웃 1/1 ]

[ 서브 변경 ]   [ 실행취소 ]   [ 세트 종료 제안 시 강조 ]
```

- 중앙에 세트 스코어, 양쪽에 큰 +1
- 서브권은 점보다 팀명 옆 표시가 먼저 보여야 한다
- 세트 종료 조건이 충족되면 +1 대신 “세트 종료 확인”이 먼저 뜬다. 확인 전에는 한 번 더 취소할 수 있다

### 3.8 알림

| 조건 | 메시지 |
| --- | --- |
| 세트 목표-1 도달 (24-x 등) | “세트 포인트” |
| 듀스 | “듀스 · 2점 차 필요” |
| 세트 종료 조건 충족 | “세트 종료 · 홈 승을 확정할까요?” |
| 경기 종료 조건 충족 | “경기 종료 · 2-0 홈 승을 확정할까요?” |
| 타임아웃 소진 | 버튼 비활성 |

### 3.9 MVP에서 하지 않는 것

- 리베로 교체 자동화
- 공식 로테이션 반칙 판정
- 챌린지 시스템
- 세부 스탯 (킬, 블로킹, 디그)

## 4. 탁구

개인전 세트제를 검증하는 종목이다. 파울 모듈은 **화면에 넣지 않는다.**

### 4.1 프리셋 값

| 항목 | 공식 기본값 (ITTF 감각) | 동호회 기본값 (1차) | 커스텀 범위 |
| --- | --- | --- | --- |
| 경기 형식 | 7판 4선승 | 5판 3선승 | 3판 2선 / 5판 3선 / 7판 4선 |
| 세트 점수 | 11 | 11 | 11 / 21 |
| 승점 차 | 2점 차 | 2점 차 | 1점 차 / 2점 차 |
| 서브 | 2점마다 교대, 듀스 후 1점마다 | 동일 | 21점제에서는 5점마다 교대 |
| 엔드 교대 | 세트마다, 결승 세트 5점(11점제) | 알림만 | 알림 on/off |
| 선수 구성 | 단식 1:1 | 단식 1:1 | 복식은 Phase 2 |

### 4.2 상태와 화면 표시

- 양쪽 선수 이름 (팀 로스터가 아니라 개인)
- 현재 세트 점수
- 세트 스코어
- 각 세트 점수 이력
- 서브권 + 이번 서브 남은 개수 (예: 서브 1/2)
- 듀스 여부

파울, 카드, 교체, 팀 파울은 렌더링하지 않는다.

### 4.3 득점

| 버튼 | 동작 |
| --- | --- |
| 선수A +1 | A 점수 +1, 서브 카운트 처리 |
| 선수B +1 | 대칭 |
| 서브 변경 | 점수 없이 서브권/카운트 교정 |
| 실행 취소 | 점수와 서브 카운트를 함께 되돌림 |

선수 선택은 경기 시작 시 이미 확정되어 있으므로, 경기 중 선수 피커는 없다.

### 4.4 서브 카운트

```text
11점제, 듀스 전
  한 선수가 2점을 서브한 뒤 상대에게 넘긴다
  화면: “김민수 서브 1/2”

11점제, 10-10 이후
  1점마다 서브를 교대한다
  화면: “듀스 · 교대 서브”

21점제, 듀스 전
  5점마다 교대 (커스텀으로 2점도 허용)
```

득점 이벤트 하나에 점수와 서브 카운트 변화를 같이 넣는다. 취소 시 둘 다 돌아가야 한다.

### 4.5 세트 · 경기 종료

배구와 같은 엔진을 쓴다.

```text
점수 >= 세트 목표 AND 점수 차 >= 승점 차
  → 세트 종료 확인
  → 세트 스코어 갱신
  → 필요 승수 도달 시 경기 종료 확인
```

10-10이면 듀스. 12-10처럼 2점 차가 나야 세트가 끝난다.

**엔드 교대 알림:** 세트 종료 확정 후 “엔드 교대”를 보여 준다. 결승 세트는 한 선수가 5점(11점제)에 도달하면 한 번 더 알린다. 알림만 하고 강제하지 않는다.

### 4.6 스코어보드 버튼 배치

```text
김민수  ●서브 1/2          SET 3          박지훈
  8                     1 - 1                 6
                 11-7 / 9-11 / 진행 중

[ +1 ]                                       [ +1 ]

[ 서브 변경 ]     [ 실행취소 ]     [ 일시정지 ]
```

농구/배구보다 더 단순한 화면이 정답이다. 큰 점수, 큰 +1, 서브 표시만 남긴다.

### 4.7 몰수

- 세트 몰수: 상대가 해당 세트를 목표 점수-0으로 가져감
- 경기 몰수: 상대가 필요 세트 승수를 채움 (예: 3-0)

### 4.8 MVP에서 하지 않는 것

- 복식 위치/서브 순서 강제
- 타임아웃 공식 1회 자동화 (필요하면 일시정지로 대체)
- 렛(let) 별도 이벤트 — 점수 없이 넘어가면 아무 입력도 하지 않으면 된다
- 경고/카드

## 5. 세 종목이 공유하는 것 / 각자 가지는 것

| 항목 | 농구 | 배구 | 탁구 |
| --- | --- | --- | --- |
| 스코어링 유형 | 시간 + 누적 | 세트 + 목표 점수 | 세트 + 목표 점수 |
| 기본 득점 버튼 | +2 +3 +1 | +1 | +1 |
| 타이머 | 필수 | 없음 | 없음 |
| 서브권 | 없음 | 필수 | 필수 + 카운트 |
| 파울 | 필수 | 없음(MVP) | 없음 |
| 교체 | 있음 | 간단 교체(선택) | 없음 |
| 타임아웃 | 있음 | 있음 | 없음(일시정지) |
| 듀스 | 없음 | 있음 | 있음 |
| 연장 | 있음 | 없음 | 없음 |
| 출전 단위 | 팀 5명 | 팀 6명 | 선수 1명 |

배구와 탁구는 **같은 세트 엔진**을 쓰고, 서브 카운트와 개인/팀 단위만 다르게 둔다. 농구만 타이머+파울 엔진을 추가한다.

## 6. 구현용 상태 요약

### 6.1 농구 스냅샷

```text
quarter, clockMs, clockRunning, started
homeScore, awayScore
homeTeamFoulsInQuarter, awayTeamFoulsInQuarter
playerFouls[playerId]
onCourtHome[], onCourtAway[]
timeoutsLeft[teamId]

inOvertime
```

### 6.2 세트 종목 스냅샷 (배구/탁구)

```text
currentSet, homeSetPoints, awaySetPoints
setHistory[{ home, away, winner }]
setsWonHome, setsWonAway
serveTeam / servePlayer
serveCount, serveLimit          // 탁구만. 배구는 항상 1
deuce
targetPoints                     // 마지막 세트면 다른 값
needMargin                       // 보통 2
```

### 6.3 종료 판정 함수 (개념)

```text
canEndPeriod(sport, snapshot, rules) -> boolean
canEndMatch(sport, snapshot, rules) -> boolean
nextPeriod(sport, snapshot, rules) -> snapshot
applyPoint(sport, snapshot, rules, side, payload) -> snapshot
applyFoul(sport, snapshot, rules, player) -> snapshot   // 농구만
```

UI는 이 함수의 결과를 받아 버튼을 잠그거나 확인 팝업을 띄운다. 화면에 종목 if문을 흩뿌리지 않는다. 스코어보드 **화면**은 종목 경로(`/match/[id]/basketball` 등)로 나누고, 종목 보드 컴포넌트 단위로 갈아끼운다.

## 7. 예외 · 분쟁

| 상황 | 처리 |
| --- | --- |
| 오터치 득점 | 실행 취소. 이미 세트가 확정됐으면 관리자가 세트 확정을 해제 |
| 종료 확인 후 항의 | 관리자만 `completed` → 정정. 대진 반영을 다시 계산 |
| 선수 미도착 | 몰수. 대진은 상대 승 처리 |
| 경기 중 선수 교체 명단 오류 | 로스터 수정은 `paused`에서만. 이미 기록된 파울/득점 선수는 유지 |
| 네트워크 끊김 | 로컬 이벤트 큐에 쌓고 재연결 시 전송. 스코어는 로컬이 우선 |
| 두 기기가 같은 경기를 염 | MVP는 동시 기록 금지. 두 번째 기기는 조회만 |

## 8. 오픈 이슈

1. 농구 자유투를 +1 수동 기록으로 둘지, “자유투 2개” 위자드를 넣을지
2. 배구 로테이션을 MVP에서 표시만 할지, 아예 뺄지
3. 탁구 21점제를 프리셋에 넣을지, 11점만 둘지
4. 토너먼트 동점 처리: 농구 연장 강제 vs 자유투 승부
5. 몰수 스코어 기본값 (농구 20-0, 배구 2-0, 탁구 3-0)을 대회마다 바꿀지
