## 3. 공통 크롬

```text
← 이전          대회 만들기          n / 4
────────────────────────────────
(단계 본문)
────────────────────────────────
[ 다음 ]  또는 4단계에서 [ 대회 만들기 ]
```

- 진행 점 4개. 현재만 강조
- `다음`은 해당 단계 잠금이 풀려야 활성
- 에러는 버튼 위, 다음 행동을 포함

카피: 버튼 `다음` / `이전` / `대회 만들기`. `게임 시작` 금지.

## 4. 단계별 와이어

### 4.1 1단계 종목

**목적:** 한 종목만 고른다. 지금은 농구만 실제 선택.

```text
종목

┌─────────────────────────┐
│ 농구                    │  ← 선택됨 (보더 primary)
│ 시간+파울               │
└─────────────────────────┘
┌─────────────────────────┐  흐림, 탭해도 선택 안 됨
│ 배구                    │
│ 세트+서브 · 지금은 선택할 수 없습니다 │
└─────────────────────────┘
┌─────────────────────────┐
│ 탁구                    │
│ 개인 세트제 · 지금은 선택할 수 없습니다 │
└─────────────────────────┘
```

진입 시 농구가 이미 선택. 배구/탁구를 탭하면 토스트 없이 카드가 그대로 (또는 짧은 “다음 종목입니다”). 알림을 길게 쓰지 않음.

잠금: 없음 (기본 선택). `다음` 항상 활성.

### 4.2 2단계 룰

**목적:** 이 대회 룰을 읽고 조정한다. 경기 시작 후 바꿀 수 없음을 한 줄로.

```text
룰
이 대회에 적용됩니다. 경기 시작 후에는 바꿀 수 없습니다.

[ 동호회 기본값 ]  ← 탭하면 공식 프리셋으로 전환
                    표시: 공식 프리셋 / 동호회 기본값

8분 × 4쿼터 · 작전타임 60초 · 파울 6아웃 · 보너스 5 · 연장 3분
↑ 하단 고정 요약. 값이 바뀔 때마다 갱신 (`rulesSummary`)

쿼터 수          −  4개  +     (2~4)
쿼터 시간        −  8분  +     (4/6/8/10/12)
작전타임         −  60초 +     (30/45/60/90)
파울 아웃           6  · 탭해서 5↔6
보너스              5번째부터 · 탭해서 5↔4
타임아웃 팀당       2회 · 탭해서 2↔1
연장                3분 · 탭해서 켜짐/없음
```

프리셋 전환 시 **커스텀을 덮어쓴다.** 확인: “동호회 기본값으로 되돌릴까요?” / 공식도 동일. (초안 앱은 확인 없이 덮음 → 넣을 것)

공식 값 (명세서): 쿼터 10분, 연장 5분, 파울 아웃 5. 쿼터 수는 4 유지. 샷클락 행 **없음**.

동호회 기본: 8분×4, 연장 3분 켜짐, 파울 6, 보너스 5, T/O 2회·60초.

제한 없음(파울)·보너스 끔은 1차 토글에 안 넣음. 5↔6 / 4↔5만.

`다음` 항상 활성 (기본값이 유효).

### 4.3 3단계 형식

```text
형식

┌─────────────────────────┐
│ 토너먼트                │
│ 싱글 엘리미네이션       │
└─────────────────────────┘
┌─────────────────────────┐
│ 리그                    │
│ 전원 대 전원 · 승 3 / 패 0 │
└─────────────────────────┘
```

기본 토너먼트. 한 개만.

토너먼트 + 연장 없음이면 `다음` 잠금 + 에러:

“토너먼트는 승부를 가려야 합니다. 이전에서 연장을 켜 주세요.”

리그는 연장 꺼도 됨 (동점 가능). 승점 커스텀 UI 없음.

조별+결선, 더블 엘리미네이션 없음.

### 4.4 4단계 기본 정보

```text
기본 정보

대회 이름
[ 주말 농구 토너먼트     ]

날짜
○ 하루    [ 2026-08-29 ]
○ 기간    [ 2026-08-29 ] ~ [ 2026-08-30 ]

코트 수 (선택)
[ 비움 = 없음 ]   또는 1 / 2 / 3 …

[ 대회 만들기 ]
```

mock: 날짜는 문자열 입력이어도 됨. 피커는 있으면 좋고 필수는 아님.

잠금: 이름 공백. 기간이면 종료 < 시작 에러 “끝나는 날이 시작보다 빠릅니다.”

코트 수 없어도 생성.

완료 → `/competition/[id]` 개요. 배너: “참가 팀/선수를 등록하세요.”

## 5. 완료 후 개요 (만들기 흐름의 끝)

만들기 직후 첫 화면. 상세 참가·대진은 화면기획 §4.4~4.5. 여기선 랜딩만.

```text
← 홈          주말 농구 토너먼트     [농구]
준비

8분 × 4쿼터 · 작전타임 60초 · 파울 6아웃 · 보너스 5 · 연장 3분
탭 → 룰 상세 (시작 전만 수정)

진행  0 / 0 경기
다음 경기  없음 · 대진을 만들면 생깁니다

[ 참가 관리 ]   [ 대진 보기 ]   [ 경기 목록 ]

참가 팀/선수를 등록하세요.
```

대진 보기: 경기 0이면 “참가 팀이 2팀 이상이면 대진을 만들 수 있습니다.”  
`이 모임의 대회로 열기` 없음.
