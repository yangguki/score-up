## A. 보드 — 경기 시작 전 시트

라우트: `/match/[id]/badminton` 진입 시 `rules` 미확정이면 시트.

```
┌─────────────────────────────────┐
│ 경기 규칙                    [x]│
│                                 │
│ 목표점수                        │
│  ( ) 21   ( ) 25   ( ) 직접 ___ │
│                                 │
│ 판수                            │
│  ( ) 1판                        │
│  (•) 3판 2선                    │
│  ( ) 5판 3선                    │
│  ( ) 선승 ___ 판                │
│                                 │
│ ※ 자체대회에서 온 경기: 기본 1판 │
│                                 │
│        [ 경기 시작 ]            │
└─────────────────────────────────┘
```

```
┌──────────────────────────────────────────┐

│                    │                     │

│                    │                     │
│        11          │         9           │
│   ░░ 탭 = +1 ░░    │   ░░ 탭 = +1 ░░     │
│                    │                     │
├────────────────────┴─────────────────────┤
│ ● 서브 홈     [일시정지]  [경기 종료]     │
```

## C. 모임 → 자체대회 열기

`/club/[id]` 액션

```
┌─────────────────────────────────┐
│ 수요일 배드민턴                  │
│ 멤버 18 · 다음 회차 토 14:00      │
│                                 │
│ [ 한 판 열기 ]  [ 자체대회 열기 ] │
│ [ 회차 만들기 ]                   │
└─────────────────────────────────┘
```

`/club/[id]/competitions/new`

```
1. 이름 · 날짜 · 장소
2. 형식  (•) 단식  ( ) 복식
3. 경기 규칙 기본
   목표점수 21/25/커스텀
   판수 (•) 1판  ( ) 3판2선 …
4. 외부 참가 허용 ( ) 
5. 모집 마감
           [ 모집 시작 ]
```

## D. 멤버 참가신청

멤버에게 보이는 카드 (`/competition/[id]` 또는 홈 할 일)

```
┌─────────────────────────────────┐
│ 9월 자체대회                      │
│ 9/28 · 시민체육관 · 단식 · 1판    │
│ 모집 ~ 9/27 20:00                │
│                                 │
│     [ 참가 신청 ]                │
└─────────────────────────────────┘
```

신청 후: 「신청됨 · 승인 대기」 [취소]  
승인 후: 「참가 확정」

비로그인 탭 → 계정 최소 로그인 시트.

## E. 운영자 — 신청·명단

`/competition/[id]/entries`

```
┌─────────────────────────────────┐
│ 참가 관리              마감 D-1  │
│ 신청 12 · 승인 9 · 대기 3        │
│                                 │
│ ▼ 신청                            │
│ ☑ 김민수  멤버  중급   [승인][거절]│
│ …                               │
│ ▼ 확정 명단 (9)                   │
│ 김민수 · 이서준 · …               │
│                                 │
│ [외부 참가자 추가]                │
│ [대진 만들기]                     │
└─────────────────────────────────┘
```

외부 추가 시트:

```
( ) 한 명 입력    (•) 여러 줄 붙여넣기
┌─────────────────────┐
│ 홍길동               │
│ 김영희               │
│ …                   │
└─────────────────────┘
[미리보기] → 확정 명단에 `외부` 뱃지

(P1) [명단 사진으로 추가] → OCR 검토 목록
```

## F. 화면 우선순위 (구현 순서)

1. 보드 규칙 시트 + 터치존 +1 (기존 보드 개조)
2. 자체대회 만들기(규칙 기본 1판) + `clubId`
3. 참가신청 · entries 승인 (계정 최소 의존)
4. roster·대진 연결
5. 외부 붙여넣기
6. (P1) OCR
