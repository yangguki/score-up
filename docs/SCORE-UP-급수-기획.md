# SCORE UP 급수 시즌 기획

| 항목 | 내용 |
| --- | --- |
| 문서명 | 기간형 급수 리그 · 결과 넣기 · 도전장 |
| 버전 | v0.2 |
| 작성일 | 2026-08-27 |
| 상태 | 초안 잠금. mock은 농구 모임 + 배드민턴 모임 1차(같은 급수·두 멤버 결과 넣기) |
| 기준 | 기획서 v0.3, 모임 기획 v0.8, 작업계획 Phase 7 |
| 목적 | 대회 리그(승3/패0)와 다른 **모임 안 기간 전적**을 고정한다 |

대회 만들기 리그·회차 5v5 보드를 대체하지 않는다. 밴드 클론(피드)도 아니다.

---

## 1. 한 줄

**급수 시즌**은 모임 멤버의 기간 전적이다. 급수는 운영자가 붙이는 라벨이고, 도전은 멤버가 멤버에게 경기를 요청하는 카드이며, 결과는 보드 없이 점수를 넣을 수 있다.

---

## 2. 왜 필요한지

주말 픽업(회차)만으로는 **시즌처럼 쌓이는 개인 급수**가 없다. 동호회는 종이 스코어를 나중에 적거나, 같은 급수끼리 한 판을 따로 한다.

| 지금 | 빠진 것 |
| --- | --- |
| 회차 5v5 보드 | 보드 없이 끝난 점수 |
| 모임 랭킹 = 회차 팀 승패 | 개인 1:1 전적·급수 칸 |
| 대회 리그 = 팀 승점 | 멤버 급수 시즌 |

---

## 3. 대회·회차와 섞지 말 것

| | 대회 리그 | 회차 | 급수 시즌 |
| --- | --- | --- | --- |
| 단위 | Competition | Session | Club + 기간(시즌 라벨) |
| 승패 | 팀 승3/패0 | 그날 A/B 팀 | **멤버 두 사람** |
| 보드 | 종목 보드 | 농구 보드 재사용 | **1차 없음** (결과 넣기) |
| 급수 | 없음 | 없음 | 초급/중급/상급 |

---

## 4. 잠긴 결정 (1차 mock)

| 결정 | 선택 | 이유 |
| --- | --- | --- |
| 종목 | **농구 모임 + 배드민턴 모임 1차.** 같은 초중상·두 멤버 결과 넣기 | 복식 4명 손결과는 배드민턴 2차 |
| 급수 | **초급 / 중급 / 상급.** 기본 중급. 모임장·운영만 지정 | ELO·자동 승급은 분쟁 |
| 기간 | 모임 `seasonLabel` 1구간. 별도 시즌 객체 없음 | 회차 랭킹과 같은 창 |
| 도전 상대 | 같은 급수 또는 **한 칸 차이**만. 초급↔상급 잠금 | 급수 의미 유지 |
| 도전 경기 | 수락 후 **결과 넣기**. 새 보드 없음 | 농구 출전 5와 안 싸움 |
| 결과 넣기 | 두 멤버 + 점수. 동점 불가. 게스트 없음 | 종목 보드 없이 전적만 |
| 랭킹 | 회차 경기 + 급수 경기. **급수별 표.** 게스트 행 없음 | 기존 회차 전적 유지 |
| 사진 업로드 | 안 함 | 이미지 공유는 API 후 |
| 자동 승급 | 안 함. 급수는 손으로만 | 시스템이 심판처럼 보이지 않게 |

---

## 5. 상태

도전 `pending` → `accepted` / `declined` / `cancelled`  
`accepted` → 결과 넣기 → `completed`

시스템이 제안하지 않는다. 사람이 보내고, 상대가 받고, 점수는 확정한다.

---

## 6. 흐름

```text
멤버 급수 지정 (운영)
 → (선택) 도전 보내기 → 수락/거절
 → 결과 넣기 (도전 수락 또는 운영자가 바로)
 → 급수별 랭킹·전적
```

본인에게 도전 불가. 같은 상대에게 `pending`이 있으면 추가 불가.  
거절·취소된 도전은 전적 없음.

---

## 7. 화면

| 경로 | 화면 |
| --- | --- |
| `/club/[id]/members` | 급수 표시. 운영자 초급/중급/상급 |
| `/club/[id]/ranking` | 급수별 표. 주석: 회차 + 급수 경기 |
| `/club/[id]/records` | 회차 카드 + 급수 경기 카드 |
| `/club/[id]/challenges` | 도전 목록 · 보내기 |
| `/club/[id]/ladder/new` | 결과 넣기. `challengeId`면 상대 고정 |

개요: `도전` / `결과 넣기` 진입 (운영·멤버). 탭 추가 없음.

### 7.1 도전 목록

```text
← 도전

[ 도전 보내기 ]

받은 요청
  한지호  →  나   중급    [ 수락 ] [ 거절 ]
보낸 요청
  나  →  박지훈  대기
완료
  김민수  21-18  박지훈
```

### 7.2 도전 보내기

상대 목록 = 활성 멤버 − 나 − 급수 2칸 차이 − pending 중복.  
잠금 카피: “초급과 상급은 바로 도전할 수 없습니다.”

확인: “박지훈에게 도전을 보낼까요?”

### 7.3 결과 넣기

```text
← 결과 넣기

상대 (도전 수락이면 고정)
  홈 [ 김민수 ]   어웨이 [ 박지훈 ]
점수
  [ 21 ]  -  [ 18 ]

[ 결과 확정 ]
```

동점·같은 사람·빈 점수 잠금. “승패가 나야 랭킹에 넣습니다.”  
확정 확인: “점수를 넣고 랭킹에 반영할까요? 보드는 열리지 않습니다.”

## 9. 카피

| 위치 | 문구 |
| --- | --- |
| 급수 | 초급 / 중급 / 상급 |
| 보내기 | 도전 보내기 |
| 응답 | 수락 / 거절 |
| 기록 | 결과 넣기 / 결과 확정 |
| 랭킹 주석 | 회차 경기와 급수 경기가 반영됩니다 |
| 동점 | 승패가 나야 랭킹에 넣습니다 |
| 급수 잠금 | 초급과 상급은 바로 도전할 수 없습니다 |
| 보드 | 보드는 열리지 않습니다 |

쓰지 말 것: `ELO`, `승급전 자동`, `업로드`(사진처럼), `게임 시작`, `1대1 보드`.
