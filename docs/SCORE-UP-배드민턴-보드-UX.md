# 배드민턴 스코어보드 UX

## 제품 잠금 (2026-09-14)

### 득점 방식
- **반절 터치 득점**: 좌/우 화면 반절을 터치하면 해당 팀에 +1점
- 기존 +1 버튼도 하단 독에 유지
- 경기 중이 아니거나 일시정지 상태면 터치 비활성화

### 목표 점수 설정
- 프리셋: **21점**, **25점**
- 직접 입력: 11~30점 범위 내 정수
- 경기 시작 전 또는 일시정지 상태에서 변경 가능

### 판수 (세트) 설정
- **1판** (setsToWin: 1)
- **3판 2선** (setsToWin: 2)
- **5판 3선** (setsToWin: 3)
- 직접 입력: 1~5판 선승
- 경기 시작 전 또는 일시정지 상태에서 변경 가능 (단, 이미 이긴 세트보다 낮게는 불가)

### 컨텍스트별 기본값
| 컨텍스트 | 목표 점수 | 판수 |
|---------|---------|------|
| 모임 회차 / 친선 | 21점 | 3판 2선 |
| 대회 (competition) | 21점 | **1판** |

### 룰 시트
- 경기 시작 전: 오버레이에 현재 룰 요약 표시 + "룰 변경" 버튼
- 일시정지 상태: 하단 독에 "룰 변경" 버튼 노출
- 룰 변경 다이얼로그에서 판수, 목표 점수, 승점 차 선택 후 "적용"

### 기타 규칙
- 승점 차: 2점 (듀스 마진)
- 서브권: 득점자 서브 (scorer 모드)
- 결승 세트 11점에서 엔드 교대 알림
- 복식은 이름만 (위치/서브 순서 강제 없음)
- 화면: 가로만 지원
- 셸: Arena 스타일 공유

### 보드 UI 요소
- 양쪽 팀명 (복식이면 슬래시로 구분)
- 현재 세트 점수
- 세트 스코어 (몇 판 이겼는지)
- 세트 이력
- 서브권 표시
- +1 버튼
- 서브 변경 버튼
- 실행 취소 버튼
- 듀스/세트포인트 알림

### 그리지 않는 것
- 서브 개수 (1/2 표시 없음, 탁구와 다름)
- 파울/카드/시계/타임아웃
- 복식 코트 위치/서브 순서 강제
- 렛 이벤트
