## 1. 한 줄

자체대회에 **클럽 회원이 아닌 사람**도 참가할 수 있다.  
명단은 **1차 수동·붙여넣기**, **2차 카메라(OCR)로 종이/화면 명단 인식 후 검토·추가**.

---

## 2. 외부 참가자 모델

| 항목 | 내용 |
| --- | --- |
| 정의 | `clubId` 멤버가 아닌 대회 참가자 |
| 최소 필드 | 표시 이름 (필수). 연락처·급수는 optional |
| 계정 | 없어도 됨 (게스트성). 나중에 초대하면 멤버 전환 later |
| 전적 | 자체대회 대진에는 포함. **모임 주간 랭킹에는 넣지 않음** (게스트와 동일 원칙) |
| 표시 | 명단에서 `외부` 뱃지 |

운영자만 추가·삭제. 외부 참가자가 앱에서 스스로 신청하는 흐름은 MVP 밖(링크 오픈 신청은 later).

---

## 3. Phase 1 — 수동 명단 (MVP에 포함)

진입: 자체대회 → 참가 관리 → **외부 참가자 추가**

| 방법 | 동작 |
| --- | --- |
| 한 명씩 | 이름 입력 → 추가 |
| 여러 줄 붙여넣기 | 줄바꿈/쉼표 구분 → 미리보기 → 확인 후 일괄 추가 |
| 멤버 명단에서 제외 | 이미 멤버면 「이미 모임 멤버입니다. 참가신청으로 받으세요.」 |

검수: 이름 10명 붙여넣기 → roster에 10행 · 외부 뱃지 · 대진 시드 가능.

---

## 4. Phase 2 — 카메라 명단 OCR (MVP 직후)

### 4.1 목표

종이 신청서·엑셀 인쇄본·다른 앱 화면을 찍어 **이름 후보 목록**을 만들고, 운영자가 **확인·수정 후** 참가 명단에 넣는다.  
자동 확정 없음 — **항상 사람 확정**.

### 4.2 플로우

```text
[명단 사진으로 추가]
 → 카메라 / 앨범
 → OCR 실행 (온디바이스 우선, 실패 시 안내)
 → 인식된 줄 목록 (체크박스)
 → 운영자가 오타 수정·제외
 → [선택 항목 추가] → 외부 참가자로 roster 반영
```

### 4.3 제품 규칙

| 규칙 | 내용 |
| --- | --- |
| 검토 필수 | OCR 결과를 바로 참가 확정하지 않음 |
| 저장 | 사진 원본은 **기본 저장하지 않음**. 인식 텍스트만 유지 (설정에서 “사진 보관” off) |
| 개인정보 | 대회 운영 목적 고지 한 줄. 대회 종료 후 외부 명단 삭제 안내 |
| 언어 | 한글 이름 우선. 영문·숫자는 줄 단위로 보여 주고 수정 |
| 실패 | 「이름을 읽지 못했어요. 다시 찍거나 붙여넣기 하세요.」 |

### 4.4 기술 메모 (구현 시)

- iOS Vision / Android ML Kit 등 **온디바이스** 우선 검토
- 서버 OCR은 계정·동의·비용 이슈로 Phase 2에서도 최후 수단
- 이 문서는 제품 범위만 잠금. SDK 선택은 Infra/Frontend 후속

### 4.5 넣지 않음 (OCR 단계)

- 얼굴 인식·출석 체크
- 신분증 촬영
- 실시간 영상에서 지속 추적
- 명단을 마케팅/외부 공유

---

## 5. 자체대회와의 연결

- 「외부 참가 허용」이 켜진 대회만 외부 추가 UI 노출
- 멤버 신청 + 외부 명단 = 하나의 **확정 roster**
- 대진은 roster 기준. 출처(멤버/외부)는 시드에 영향 없음
