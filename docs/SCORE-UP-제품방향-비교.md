현행 **현장 대회 도구(A)** 를 제품 중심으로 잠근다. 모임은 홈 `내 모임` 섹션으로 얹고, Primary CTA를 모임으로 옮기지 않는다.

---

## 1. 왜 비교했나

오픈 이슈였던 두 결정:

1. 제품 한 줄: 현장 대회 도구 **유지** vs 모임 OS로 **중심 이동**
2. 홈 Primary: **대회 만들기** vs **내 모임/회차**

H1 톤 비교와 같이 버전을 나란히 둔 뒤 골랐다. 보드·종목 룰·Expo 단일 코드는 공통이다.

---

## 3. 검수 질문 → 답

1. A에서 모임이 묻히나? → Phase 7 모임(회차·급수)은 홈 `내 모임`으로 들어간다. Primary를 바꾸지 않아도 주간 픽업은 열린다.
2. B에서 대회가 부차인가? → 그렇다. 1차 페르소나는 리그/대회 운영자. 기획서 한 줄은 **현장 경기 운영**이지 모임 OS가 아니다.
3. C 듀얼 CTA가 선택 마비인가? → 그렇다. V2 히어로를 기각한 이유와 같다.
4. 보드 3초 경로? → A도 진행 중 카드가 종목 보드로 간다.
