## 아직 없는 문서 (기획서 §19)

- MVP 범위 확정서 — 지금은 기획서 §12 + 작업계획 §6이 대행
- 데이터/권한 초안 — 기획서 §11·§14, 화면기획 §6이 대행. 모임 권한은 `docs/SCORE-UP-모임-기획.md` §14

필요해지면 기획자가 초안을 만들고 Manager가 작업계획에 연결한다.
