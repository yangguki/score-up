## 1. 설계 원칙

1. **준비와 기록을 나눈다.** 대회/대진/룰은 시작 전에 끝낸다. 경기 화면에는 스코어와 제재만 남긴다.
2. **3초 안에 누른다.** 득점·파울·+1은 스크롤 없이 첫 화면에 있다.
3. **종목에 없는 것은 그리지 않는다.** 탁구 보드에 파울 자리를 비워 두지 않는다. 셸(좌우 팀 색·거대 점수·하단 독)은 농구와 같고, 버튼·중앙 메타만 종목별이다.
4. **시스템이 제안하고 사람이 확정한다.** 세트/경기 종료는 팝업으로 한 번 더 받는다.
5. **실수는 되돌린다.** 실행 취소는 경기 화면 하단 고정이다.
6. **참석과 출전을 나눈다.** 모임 회차 투표는 제품 Phase 3. mock은 홈 `내 모임`·스택에만. 탭은 추가하지 않는다. 상세 `docs/SCORE-UP-모임-기획.md`.

## 2. 정보 구조

```text
앱
├─ 홈
│   ├─ 진행 중 경기
│   ├─ 내 대회
│   ├─ 내 모임                 ← mock. 탭 아님. 로그인 후 홈 섹션
│   └─ 빠른 친선경기
├─ 대회
│   ├─ 개요
│   ├─ 참가 (팀/선수)
│   ├─ 대진 / 순위
│   ├─ 경기 목록
│   └─ 룰·설정
├─ 경기
│   ├─ 출전 명단
│   ├─ 스코어보드          ← 종목별 화면. 메인은 농구 보드
│   │   ├─ /match/[id]/basketball
│   │   ├─ /match/[id]/volleyball
│   │   ├─ /match/[id]/table-tennis
│   │   ├─ /match/[id]/badminton
│   │   ├─ /match/[id]/squash
│   │   ├─ /match/[id]/soccer
│   │   ├─ /match/[id]/futsal
│   │   └─ /match/[id]/baseball
│   ├─ 로스터/교체
│   ├─ 타임라인
│   └─ 결과
├─ (스택) 모임 `/club/[id]` (mock. 농구 + 배드민턴 1차)
│   ├─ 개요 / 회차 / 멤버
│   ├─ 랭킹 / 전적             ← 회차 + 급수 경기 · 멤버
│   └─ 정기 규칙 · 설정
└─ 설정 (이 기기 계정, 종목 프리셋, 홈 시안 H1/H8/H9, 디자인 키트)
```

MVP 탭은 홈 / 대회 / 설정 세 개다. **모임 탭을 추가하지 않는다.** 경기는 대회 또는 홈의 진행 중 카드에서 들어간다. 모임은 계정 이후 홈 `내 모임` → 스택. 범위 `docs/SCORE-UP-모임-기획.md` v0.8. 화면 `docs/SCORE-UP-모임-상세.md`.

## 3. 핵심 사용자 흐름

### 3.1 대회를 만들어 결승까지

```text
홈
 → 대회 만들기
 → 종목 선택
 → 룰 확인/조정
 → 형식 선택 (토너먼트 / 리그)
 → 대회 이름·날짜
 → 팀/선수 등록
 → 대진 생성
 → 경기 카드 선택
 → 출전 명단 확인
 → 스코어보드
 → 결과 확정
 → 대진표에 승자 반영
 → 다음 경기 반복
 → 대회 종료 (우승/최종 순위)
```

### 3.2 대진 없이 바로 치는 친선

```text
홈 → 빠른 친선경기 CTA
 → 종목 선택
 → 룰 확인
 → 팀 또는 선수 이름만 입력
 → 스코어보드
 → 결과 저장 (대회 없이 기록만 남김)

홈 → 종목 타일
 → 친선 (종목 선택 없음)
 → 룰 확인
 → 이름 입력
 → 스코어보드
```

친선은 진입을 짧게 하되, 홈의 기본 CTA는 **대회 만들기**다. 스코어 앱으로만 쓰이지 않게 하기 위해서다.

### 3.3 기록원이 배정된 경기를 연다

```text
홈 진행 중 / 대회 경기 목록
 → 내 담당 경기
 → 출전 명단이 있으면 바로 스코어보드
 → 없으면 선발 확인 후 시작
```

### 3.4 모임 회차 (mock. 제품 Phase 3-A)

```text
모임 만들기 → 멤버 초대 → 회차(또는 매주 정기)
 → 참석 투표 → 마감 → 참석자 확정
 → 팀 나누기(1차 수동) → 출전 명단 → 종목 스코어보드
 → 결과 → 모임 전적·랭킹
```

참석(회차에 옴)과 출전(그 경기 선발)을 한 화면에서 합치지 않는다. 보드를 새로 만들지 않는다. 랭킹은 회차 경기 + 급수 경기·멤버. 진입은 홈 `내 모임`이다. **기본은 농구 5v5·모임장=기록원.** 인원 미달(8~9명)이면 운영자가 4대4로 나눈다. 전략 분석은 제품 Phase 3-C.

**배드민턴 모임 1차**는 농구 모임 스택을 재사용한다 (`docs/SCORE-UP-모임-기획.md` §21). 회차 confirming은 **한 판 열기**(단식/복식). 5v5를 복사하지 않는다. 대회·친선 배드민턴 보드는 유지.

화면 와이어: [`docs/SCORE-UP-모임-상세.md`](SCORE-UP-모임-상세.md).

## 4. 화면별 명세

### 4.1 홈

**목적:** 지금 할 일(진행 중 경기)과 만들 일(새 대회)을 한 화면에서 고른다.

상세 와이어·상태 매트릭스·카드 필드: [`docs/SCORE-UP-홈-상세.md`](SCORE-UP-홈-상세.md). **톤·허브는 H1 Arena가 제품 기본.** H8 Lift · H9 Play는 비교. 카드 규칙(라이브만 점수)은 V1. V2 히어로는 쓰지 않는다.

| 영역 | 내용 |
| --- | --- |
| 상단 | `SCORE UP` + `지금 할 일과 만들 일`. H1 우측 `운영자`(설정). H8 우측 **원형 Up 로고**(설정). H9 우측 **원형 민트 up**(설정) |
| 종목 | H1: 2열 모자이크. H8: 세로 4열 / 가로 8열. H9: 세로 작은 2열 블롭 / 가로 4열×2줄. 탭하면 `/friendly?sport=`. 모임은 농구 + 배드민턴 1차 |
| CTA | 종목 아래 `대회 만들기` / `빠른 친선경기` (H9는 최근 활동 독) |
| 지금 할 일 | 라이브류를 먼저, 이어서 오늘 배정·미종료. 최대 5. 라이브만 점수. 대기는 `vs` |
| 내 대회 | `completed` 제외 2~5개. 다음 미진행 경기 수. 빈 홈에서는 섹션 숨김 |
| 내 모임 | 로그인 후 카드. 다음 회차·투표 상태. mock 시드 농구+배드민턴. 탭 아님 |
| 키트 | `/kit/arena` H1. `/kit/lift` H8. `/kit/play` H9. 설정에서 진입 |

빈 상태: “첫 대회를 만들면 선수, 대진, 스코어가 하나로 이어집니다.”

경기 카드 탭: `scheduled`/`lineup` → 출전, 그 외 진행류 → 종목 보드. 친선도 진행 중 목록에 넣고 라운드 자리에 `친선`.

**시안 비교**

| 시안 | 한 줄 | 결정 |
| --- | --- | --- |
| V1 기획 원안 | 진행 중 카드 → 내 대회 → CTA | 카드·섹션 IA 채택 |
| V2 지금 할 일 | 다음 행동 히어로 | 기각 (CTA 중복) |
| V3 라이브 핀 | 큰 스코어 핀 | 라이브 점수 크기만 |

| **H9 Play** | 흰 캔버스·민트 ‘업’·블롭 종목 | **비교** · 잠금 아님. 테니스/족구/기타 없음 |

### 4.2 대회 만들기 (4단계)

한 화면 스크롤이 아니라 **단계형**으로 둔다. 룰을 대충 넘기지 않게 하기 위해서다.

상세 와이어: [`docs/SCORE-UP-대회-만들기-상세.md`](SCORE-UP-대회-만들기-상세.md). 참가 팀은 4단계에 넣지 않는다.

**1단계 종목**

- 카드: 홈 8종목 (농구, 배구, 탁구, 축구, 야구, 배드민턴, 스쿼시, 풋살)
- 각 카드에 한 줄: “시간+파울”, “세트+서브”, “개인 세트제” 등
- 한 개만 선택

**2단계 룰**

- 선택한 종목의 동호회 기본값을 미리 채운다
- 공식 프리셋 토글은 **농구만**. 배구·탁구는 동호회 값 + 커스텀 토글
- 항목은 종목 룰 명세서의 커스텀 표만 보여 준다
  - 농구: 쿼터 수(최소 2), 쿼터 시간, 작전타임 시간, 파울 아웃, 팀 파울 보너스, 타임아웃 횟수, 연장
  - 배구: 선승 형식, 세트 점수, 승점 차, 타임아웃, 로테이션 표시(선택)
  - 탁구: 선승 형식, 세트 점수, 승점 차, 복식은 이름만
  - 배드민턴·스쿼시: 랠리 세트, 득점자 서브
- 화면 하단 요약: “8분 × 4쿼터 · 작전타임 60초 · 파울 6아웃 · 보너스 5”

**3단계 형식**

- 토너먼트 (싱글 엘리미네이션)
- 리그 (전원 대 전원)
- 토너먼트인데 농구 연장을 끄면 에러: “토너먼트는 승부를 가려야 합니다”

**4단계 기본 정보**

- 대회 이름
- 날짜 (단일 또는 기간)
- 코트 수는 MVP에서 선택. 없어도 생성 가능

완료 후 대회 개요로 이동하고, 다음 할 일로 “참가 팀/선수를 등록하세요”를 띄운다.

### 4.3 대회 개요

| 영역 | 내용 |
| --- | --- |
| 헤더 | 대회명, 종목 필, 상태(준비/진행/종료) |
| 룰 요약 | 2단계 요약 문구. `룰 수정`(prep) / `룰 보기`. 대진·일정 후 잠금 |
| 진행 | 종료 경기 / 전체 경기 |
| 다음 경기 | 가장 가까운 `scheduled` 경기 1개 |
| 액션 | 참가 관리, 대진 보기, 경기 목록 |

### 4.4 참가 팀 / 선수

상세 와이어: [`docs/SCORE-UP-참가-상세.md`](SCORE-UP-참가-상세.md). 만들기 위저드 밖, 개요 → 「참가 관리」.

**팀 종목 (농구, 배구)**

```text
참가 팀
[ + 팀 추가 ]

호랑이
  12 김민수 · 5 박지훈 · 7 이서연 …  (8명)
  [ 선수 추가 ]

독수리
  선수 0명 · 로스터를 채워 주세요
```

- 팀 추가: 팀 이름
- 선수 추가: 이름, 등번호. 포지션은 선택
- 같은 대회에서 등번호+팀 중복 방지
- 대진 생성 전 최소 조건
  - 토너먼트: 팀 2개 이상
  - 권장: 팀당 선수 농구 5, 배구 6. 미달이면 경고만 하고 진행은 가능

**개인 종목 (탁구)**

- 팀 계층 없이 선수 목록만
- 시드 번호 선택 필드 (선택)

**빠른 등록:** 여러 줄을 붙여넣기 (이름 또는 이름,번호). MVP에서 가능하면 넣고, 어려우면 Phase 2.

### 4.5 대진 생성 · 대진표

**생성 전**

- 참가 수 확인
- 시드: 수동 / 랜덤
- 토너먼트: 4/8/16… 브래킷. 부족하면 BYE 자동
- 리그: 라운드 수 1회 또는 홈앤어웨이(2회). MVP는 1회만

**토너먼트 화면**

```text
        4강              결승             우승
  [호랑이 ] 
  [독수리 ]  →  [     ] 
  [상어   ]
  [BYE    ]  →  [상어  ]
```

- 각 칸은 경기 카드. 상태 필: 대기 / 진행 / 종료
- 종료된 칸은 점수와 승자를 보여 준다
- 진행 중 칸은 현재 스코어
- 칸을 누르면 출전 명단 또는 스코어보드
- BYE는 자동 승, 다음 라운드에 미리 채워 둠
- 드래그로 위치 변경은 첫 경기가 시작되기 전만
- 대진이 있으면 `대진 복사`. 카톡·문자 붙여넣기. **실시간 링크·이미지는 없음** (제품 Phase 2)

**리그 화면**

**리그 화면**

- 위: 순위표 (순위, 팀, 승, 패, 득실, 승점)
- 아래: 라운드별 경기 목록
- 농구 승점 기본 승3/패0. 배구는 세트 스코어에 따라 3-0/3-1=3점, 3-2=2점, 2-3=1점을 선택으로 (기본은 승3/패0으로 단순화 가능)
- MVP 리그 승점은 **승 3 / 패 0**으로 고정하고, 세트 승점제는 Phase 2로 명시
- 일정이 있으면 `순위 복사`. 같은 텍스트 공유. 실시간 링크 없음

### 4.6 경기 목록

필터: 전체 / 오늘 / 대기 / 진행 / 종료

한 행:

| 시간 | 대진 | 상대 | 상태 | 스코어 |
| --- | --- | --- | --- | --- |
| 14:00 | 4강 | 호랑이 vs 독수리 | 진행 | 24-18 Q2 |

행 탭 → 상태에 따라 출전 명단 또는 스코어보드 또는 결과.

### 4.7 출전 명단 (경기 시작 전)

팀 종목 중 **농구만** 이 화면. 배구는 로테이션 전까지 보드로 바로 간다. 탁구는 건너뛴다.

```text
호랑이 선발 (5)          독수리 선발 (5)
● 12 김민수              ● 4 최유진
● 5 박지훈               …
벤치
○ 21 한지호

[ 경기 시작 ]
```

- 선발 수가 **그 경기** 출전 인원(`rules.starters`)과 같아야 보드로 들어갈 수 있다. 대회·친선 농구는 5. 모임 4v4 회차는 4.
- [ 경기 시작 ]은 출전 확정 후 **종목 스코어보드로 이동**한다. 상태 `lineup` → `in_progress`
- 농구 시계는 이 시점에 돌지 않는다. 보드에 들어간 뒤 보드의 **경기 시작**을 눌러야 1쿼터 시계가 돈다
- 선수를 고르지 않은 친선은 출전 명단을 건너뛰고 바로 농구 보드로 간다. 역시 시계는 정지 상태다

### 4.8 스코어보드 (메인)

경기 중 화면의 90%는 여기다. **셸은 농구와 같다**(좌우 팀 색 풀블리드, 거대 총점, 오버레이 헤더, 하단 독). 버튼·중앙 메타만 종목별로 다르다. 상세 버튼은 룰 명세서를 따른다. **가로만** — 세로는 「가로로 돌려 주세요」.

**라우트**

경기의 정체성은 `/match/[id]` 다. 스코어보드 **화면**은 종목 슬롯으로 나눈다. 버튼마다 종목 if문을 흩뿌리지 않는다.

| 경로 | 역할 |
| --- | --- |
| `/match/[id]/basketball` | 농구 보드. 쿼터·시계·파울·T/O |
| `/match/[id]/volleyball` | 배구 mock 보드. +1·서브·듀스·세트/경기 확정 |
| `/match/[id]/table-tennis` | 탁구 mock 보드. +1·서브 카운트·듀스·세트/경기 확정 |
| `/match/[id]/badminton` | 배드민턴 mock. 탁구 보드 공유. 득점자 서브 |
| `/match/[id]/squash` | 스쿼시 mock. 탁구 보드 공유. 득점자 서브 |
| `/match/[id]/soccer` | 축구 mock. 전후반 시계·골·카드 |
| `/match/[id]/futsal` | 풋살 mock. 전후반 시계·골·카드·누적 파울 힌트 |
| `/match/[id]/baseball` | 야구 mock. 이닝·아웃·득점 |
| `/match/[id]/scoreboard` | 호환용. 경기의 `sportId`로 위 종목 경로로 보낸다 |

URL의 종목과 경기의 `sportId`가 다르면 올바른 종목 보드로 보낸다. 진행 중 카드·출전 확정·친선 시작은 모두 `sportId` 경로로 들어간다.

**공통 크롬**

| 위치 | 요소 |
| --- | --- |
| 좌우 | 팀 색 반쪽 + 거대 총점 + 종목 메타(서브/파울/공격 등) |
| 오버레이 헤더 | 나가기 · 중앙(시계/세트/이닝) · 더보기. 진행 중 나가기는 “경기 중 · 나가기” 확인 |
| 더보기 | 몰수, 중단, 룰 보기(읽기), 타임라인. 종목 종료(쿼터/하프)가 있으면 여기 |
| 하단 독 | 팀별 `BoardKey`, 최근 이벤트 1~3(탭하면 타임라인), 실행 취소·시계/서브 변경 |

**농구** (`/match/[id]/basketball`)

- 좌우 큰 총점, 중앙 쿼터+시계+팀 파울
- 좌우 +2 +3 +1, 파울, 교체, 타임아웃
- 보너스면 상대 +1 강조
- **첫 입장:** 시계는 정지. 가운데 **경기 시작**. 누르기 전에는 득점·파울·T/O를 잠근다
- 이미 진행 중이던 경기(시드 등)는 시계 정지 + 하단 **재개**
- **T/O:** 경기 시계 정지, 화면 중앙에 작전타임 카운트다운(룰의 작전타임 초). 끝나면 정지 유지, **재개**로 경기 시계를 다시 돌린다. 중간에 **타임아웃 종료** 가능
- 시계 0이면 하단이 “쿼터 종료 확정”으로 바뀜
- 쿼터 사이는 **다음 쿼터 시작**

**배구**

- 좌우 세트 점수, 중앙 세트 스코어와 세트 이력
- 서브권 표시
- 좌우 큰 +1, 타임아웃
- 듀스/세트포인트 문구
- 종료 조건 충족 시 “세트 종료 확정”

**탁구**

- 좌우 선수명+세트 점수, 중앙 세트 스코어
- 서브권과 1/2 카운트
- 좌우 +1만
- 파울/교체/타임아웃 자리 없음

**배드민턴·스쿼시** (`/match/[id]/badminton`, `/match/[id]/squash`)

- 탁구 보드와 같은 랠리 세트 레이아웃
- 서브는 **득점자**가 가짐 (탁구의 2점 교대와 다름)
- 복식은 이름만. 위치/서브 순서 강제는 Phase 2

**축구·풋살** (`/match/[id]/soccer`, `/match/[id]/futsal`)

- 좌우 총점, 중앙 전후반 시계
- +1 골, 옐로/레드 카드 메모
- 풋살만 누적 팀 파울·PK 힌트(6번째 등). 축구에는 파울 카운트 없음

**야구** (`/match/[id]/baseball`)

- 좌우 총점, 중앙 이닝·초/말·아웃
- +1 득점, 아웃 버튼. 볼/스트라이크·주자 진루 없음

**반응형 (mock 보드 공통)**

- **가로만.** 폭 > 높이일 때만 보드. 세로는 접지 않고 「가로로 돌려 주세요」 + 나가기
- 짧은 가로(높이 < 520)는 `compact`(점수·헤더만 조금 줄임). 세로 스택·820 접힘 **없음**
- **시각 위계:** 총점 최대 · 득점/제재는 `BoardKey`(작게) · 하단 독 고스트 `sm`
- 8종목 모두 농구와 같은 좌우 색면 셸. 종목에 없는 키는 그리지 않음

**확인 팝업 (공통)**

```text
세트 종료
홈 25 - 20 어웨이
이 세트를 홈 승으로 확정할까요?

[ 마지막 점수 취소 ]   [ 확정 ]
```

확정 전에는 아직 다음 세트로 넘어가지 않는다.

### 4.9 선수 피커 (농구 득점/파울)

스코어보드 위에 올라오는 시트.

```text
홈 득점 +2
출전 중
12 김민수  파울 2
5 박지훈   파울 5 · 다음 아웃
[ 팀 득점으로 기록 ]
```

- 파울 아웃 선수는 파울 피커에 없고, 득점 피커에도 없다
- 한 번 더 탭하면 확정. 실수 방지를 위해 길게 누르기는 쓰지 않는다

### 4.10 교체 (농구, 선택적 배구)

```text
OUT  12 김민수
IN   벤치에서 선택
[ 교체 확정 ]
```

파울 아웃은 IN 후보가 될 수 없다. 출전 인원이 미달이면 재개 버튼을 잠근다.

### 4.11 타임라인

이벤트 최신순.

| 시각 | 내용 | 액션 |
| --- | --- | --- |
| Q2 05:32 | 홈 12번 +2 | 취소 |
| Q2 05:48 | 어웨이 4번 파울 (개인 3, 팀 4) | 취소 |
| Q2 06:10 | 홈 타임아웃 | 취소 |

- 이미 revoke된 줄은 취소선
- 세트/쿼터 헤더로 구간을 나눈다
- `completed` 이후에는 관리자만 취소 가능, 취소하면 결과 재계산 경고

### 4.12 결과

```text
호랑이  72  -  68  독수리
Q1 18-16 · Q2 20-14 · Q3 16-20 · Q4 18-18

승: 호랑이
대진: 결승 진출

[ 결과 복사 ]
카톡·문자로 붙여넣기. 실시간 링크는 없습니다.
[ 대진표로 ]  [ 다음 경기 ]
```

배구/탁구는 세트 이력(25-20, 23-25, 15-10)을 보여 준다.

확정과 동시에 브래킷/순위표를 갱신한다. 실패하면 결과 화면에 “대진 반영 실패 · 다시 시도”를 남긴다. 경기 결과 자체는 이미 저장한다.

`결과 복사`는 점수·세트/쿼터 이력·승자를 텍스트로 넣는다. 조회용 URL을 만들지 않는다.

### 4.13 빠른 친선경기

대회 만들기 1~2단계 + 팀/선수 이름 두 칸만 받고 바로 종목 스코어보드로 간다. 농구는 `/match/[id]/basketball`. 선수가 있으면 출전 명단을 거친다.

- 홈 **빠른 친선경기** CTA → `/friendly`. 종목 선택 영역을 보여 준다
- 홈 종목 타일 → `/friendly?sport=`. 이미 종목을 알고 들어오므로 **종목 선택은 숨긴다** (힌트에 종목명만)
- 대진 없음
- 결과는 “친선 기록” 목록에만 남김
- “이 경기를 대회로 승격”은 Phase 2

### 4.14 설정

탭. 이 기기 로그인 `/login` (이름만. 모임·투표용).

| 영역 | 내용 |
| --- | --- |
| 계정 | 이 기기 이름. 홈 `운영자`는 라벨·설정으로. 서버 계정 없음 |
| 저장 | 이 기기 persist. 새로고침해도 유지. `시드 데이터로 되돌리기` |
| 프리셋 | 홈 8종목 동호회 요약 |

## 6. 권한과 화면 차이

| 화면 | 관리자 | 기록원 | 조회 (Phase 2) |
| --- | --- | --- | --- |
| 룰 수정 | 시작 전 | 보기만 | 보기만 |

## 7. 디바이스 · 레이아웃

| 맥락 | 디바이스 | 방향 | 이유 |
| --- | --- | --- | --- |
| 대회 생성, 선수 등록, 대진 | 폰 또는 태블릿 | 세로 | 목록/폼 |
| 스코어보드, 교체, 피커 | 태블릿·폰 | **가로만** | 좌우 팀 색 + **큰 점수** · 작은 액션 키 |
| 폰에서 스코어 | 가로로 돌려 사용 | 세로 레이아웃 없음 | 「가로로 돌려 주세요」 |

**총점이 주인공**, 득점·제재는 `BoardKey`로 작게. 하단 독(실행 취소 등)은 `sm`. 짧은 가로만 compact.

가독성:

- 총점 숫자는 화면에서 가장 크다
- 액션 버튼은 점수보다 한 단계 작게 (현장 한 손 탭은 유지)
- 체육관 조명 대비를 위해 연한 회색 위 연한 숫자는 쓰지 않는다
- 실수 입력 버튼(몰수, 경기 종료)은 더보기 안에 둔다

## 8. 주요 화면 이동

```text
홈 ──대회 만들기──▶ 종목 ▶ 룰 ▶ 형식 ▶ 정보 ──▶ 대회 개요
                                              ├─ 참가
                                              ├─ 대진 ──▶ 경기 칸 ──▶ 출전 명단 ──▶ 종목 스코어보드
                                              └─ 경기 목록 ────────────┘              │
                                                                                     ▼
홈 진행 중 카드 ──────────────────────────────────────────────────────────────▶ 스코어보드
                                                                                     │
                                                                              결과 확정
                                                                                     ▼
                                                                              대진 / 순위
```

스코어보드에서 대진으로 나갈 때 경기가 `in_progress`면 “기록은 계속 저장됩니다”를 보여 준다. **농구 시계는 보드를 떠나면(언마운트) 자동 `paused`.** 재개는 보드의 재개 버튼만.

## 9. 카피 톤

- 버튼은 동사: 대회 만들기, 경기 시작, 세트 종료 확정, 실행 취소
- 알림은 짧게: “12번 파울 아웃”, “듀스 · 2점 차”, “보너스 상황”
- 심판을 대체하는 문장은 쓰지 않는다. “퇴장됩니다”가 아니라 “출전 불가 · 교체하세요”
- 에러는 다음 행동을 같이: “팀이 2개 필요합니다. 참가에 팀을 추가하세요”
