## 1. 한 줄

**배드민턴 클럽의 주간 픽업 모임과 월 1회 자체대회를 앱으로 돌린 뒤, 반응을 보고 다른 종목을 연다.**

---

## 2. 가설

배드민턴 모임장이 SCORE-UP으로 (1) 매주 참석·한 판·전적을 반복하고 (2) 한 달에 한 번 멤버 참가신청으로 자체대회를 끝까지 운영하면, 카톡·엑셀 명단 없이 앱에 남는다.  
반응을 본 뒤에만 농구 등 다른 종목 깊이를 올린다.

**반증:** 파일럿 1클럽에서 주간 루프 또는 자체대회 완주가 실패하거나, 명단·점수를 다시 카톡으로 되돌리면 범위 재검토.

---

## 3. 넣는 것 (MVP)

### 3.1 주간 모임
- 배드민턴 모임 만들기 · 멤버 초대/승인
- 회차 투표 · 단식/복식 **한 판 열기** · 전적·급수(초/중/상)
- 계정 최소 (신청·투표 주체 식별)

### 3.2 보드
- 터치존 **탭 = +1**
- 목표점수 **21 / 25 / 커스텀(11~30)**
- **판수 커스텀** (1판 · 3판 2선 · 5판 3선 · 선승 커스텀)
- 모임/친선 기본: 21점 · 3판 2선

### 3.3 자체대회
- 모임에서 **자체대회 열기** (`Competition.clubId`)
- 멤버 **참가신청 → 승인 → 명단 → 대진 → 보드**
- 자체대회 경기 기본: **1판** · 21점 (대회·경기에서 커스텀 가능)
- 외부 참가자: **수동·붙여넣기** (OCR은 직후 단계)

### 3.4 확장 원칙
- 배드민턴 파일럿 피드백 전에는 **타 종목 엔진·모임 2차 기능 동결**

---

## 4. 빼는 것

- 회비·셔틀 정산·멀티코트·대기 호출·민턴인 클론
- H8/H9 홈 시안 제품 잠금 작업
- 8종목 룰 엔진 동시 확장
- A~D조 자동 / ELO / 복식 4명 급수 결과(기존 2차 후보 유지)
- Cognito full · 푸시 필수
- OCR **자동 확정**, 얼굴인식, 신분증

---

## 5. 의도적 later

- 카메라 명단 OCR (P1, 수동 명단 다음)
- 한 회차 여러 판 · 남복 필터
- 오픈 링크로 비회원 신청
- 타 종목 모임 심화 (농구 등)
- 대회 Phase 재가속 (배드민턴 밖)

---

## 6. 성공 조건 (파일럿 1클럽)

| # | 조건 |
| --- | --- |
| 1 | 주간 픽업 **3회** 투표→한 판→전적 완주 |
| 2 | **자체대회 1회** 멤버 신청으로 명단 채우고 결승까지 보드 완주 |
| 3 | 자체대회 경기는 기본 1판으로 운영, 최소 1경기는 판수/점수 커스텀 검증 |
| 4 | 외부 참가자 ≥2명 수동 추가 후 대진 포함 |
| 5 | 카톡 참석·명단 투표 **상시 복귀 없음** (파일럿 기간) |

## 7. 다음 2주 P0 (요약)

1. 본 확정서·보드·자체대회·외부참가 문서를 기획 기준으로 채택
2. 배드민턴 보드: +1 터치존 · 21/25/커스텀 · 판수 커스텀 · 자체대회 기본 1판
3. 모임→자체대회 브릿지 + 멤버 참가신청
4. 외부 참가자 수동·붙여넣기
5. 계정 최소 (신청 식별)
6. 파일럿 클럽 1곳 섭외
