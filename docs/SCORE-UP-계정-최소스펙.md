## 1. 한 줄

**투표·참가신청·멤버십의 “누구”를 기기 밖으로도 같은 사람으로 식별**할 수 있는 최소 계정.  
서버 풀스택이 아니라, 배드민턴 모임·자체대회 파일럿을 막지 않을 정도만.

---

## 2. 왜 지금 필요한가

| 기능 | 계정 없이 | 계정 최소 |
| --- | --- | --- |
| 이 기기 모임장 혼자 조작 | 가능 (현 mock) | — |
| 멤버가 **다른 폰**에서 참석 투표 | 불가·충돌 | 필요 |
| 자체대회 **참가신청** | 누구 신청인지 모름 | 필요 |
| 초대 링크 가입·승인 | 기기 로컬 id만으론 재설치·다기기에 깨짐 | 필요 |

모임 기획 §7.1: 계정 없이 투표·멤버·승률이 성립하지 않는다.

---

## 3. 넣는 것 (MVP)

### 3.1 신원

| 항목 | 규칙 |
| --- | --- |
| `accountId` | 안정적 UUID. 기기 로컬에 캐시 |
| 표시 이름 | 필수. 모임·대회 명단에 보임 |
| 연락처 | **이메일 또는 휴대폰 중 하나** (인증 코드 1회). 둘 다 필수는 아님 |
| 비밀번호 | 이메일 가입 시 최소 비밀번호 **또는** 매직링크/OTP만 (구현 한 가지로 잠금) |
| 아바타 | 없음 (1차) |

**추천 잠금 (이 문서 기본):**  
`휴대폰 번호 + SMS OTP` **또는** `이메일 + 매직링크/OTP` 중 **하나를 제품이 고른다.**  
파일럿 한국 클럽이면 **휴대폰 OTP**가 마찰이 적음. (최종 택 1은 Infra와 Day 1에 확정)

### 3.2 세션

- 로그인 유지(리프레시). 로그아웃 가능.
- 한 계정 · 여러 기기 허용 (파일럿 필수).
- 동시 보드 기록 2대는 기존 룰: MVP는 두 번째 기기는 조회만 (룰 명세서 §7).

### 3.3 모임 멤버 바인딩

```text
ClubMember = { clubId, accountId, role, playerId?, displayNameSnapshot, status }
status: pending | active | rejected | removed
```

- 초대 링크 → 로그인/가입 → `pending` → 모임장 승인 → `active`
- 즉시 가입 없음 (모임 기획 잠금 유지)
- `playerId`: 전적용. 없으면 승인 시 자동 생성

### 3.4 자체대회 신청 바인딩

```text
CompetitionEntry = { competitionId, accountId?, externalGuestId?, status, appliedAt }
```

- 멤버 신청: `accountId` 필수
- 외부 수동 명단: `externalGuestId` (계정 없음) — 외부참가자 문서

### 3.5 기존 「이 기기 로그인」과의 이관

1. 로컬 `deviceAccount` 있으면 첫 서버 계정 연결 시 **이관 확인** 시트
2. 로컬 모임/회차 데이터를 새 `accountId`에 귀속 (충돌 시 운영자=이 기기 사용자 우선)
3. 이관 거부 시 로컬은 읽기 전용 안내

## 5. API·저장 (개념만)

| 능력 | MVP |
| --- | --- |
| `POST /auth/otp/request` · `verify` | 또는 매직링크 |
| `GET/PATCH /me` | 표시 이름 |
| `POST /clubs/:id/invites/accept` | 로그인 필요 |
| `POST /competitions/:id/entries` | 멤버 신청 |
| 권한 | club role + competition host |

로컬 mock 유지 경로: 서버 없을 때 **단일 시뮬레이터 계정 스위치**(개발용)는 허용. 파일럿은 실OTP.

동기화: 오프라인 투표 큐는 later. MVP는 **온라인 필수**로 참가신청·투표 (보드 경기는 기존 로컬 우선 가능).

## 8. 성공 기준 (계정 최소만)

1. 폰 A 모임장, 폰 B 멤버로 **같은 회차 투표**가 서로 보임
2. 폰 B에서 자체대회 **참가신청** → 폰 A에서 승인
3. 앱 재설치 후 같은 OTP로 로그인 → 멤버십 유지
4. 외부 참가자는 계정 없이 명단 추가 가능 (운영자)
