# SCORE UP 홈 UX — 완전 다른 서비스 벤치마크

H1·H5가 비슷한 이유: **같은 Arena 다크 + 앰버 + 카드**. H5는 레이아웃만 바꿨다.  
아래는 **스포츠 점수판이 아닌** 제품에서 가져온 반대축이다.

| 벤치마크 | 카테고리 | 한 줄 DNA | SCORE UP에 대입하면 |
| --- | --- | --- | --- |
| **Strava** | 피트니스 | 흰 캔버스 + **액센트 색 하나**(#FC4C02) + 숫자 3칸 | 라이브 = 3-up 스탯, 카드↓ |
| **Linear** | 이슈 트래커 | 밀도·타이포 weight·리스트 행 | 대회/CTA를 **행**으로 (큰 버튼 히어로 X) |
| **Raycast** | 런처 | 검색·명령 우선, 크롬 최소 | “지금 할 일” 큐가 본체 |
| **Letterboxd** | 영화 로그 | 시네마 다크 + **그린만** CTA | (대안) 포스터형 종목 — 미적용 |
| **Duolingo** | 학습 | 밝고 게임화 | 운영 툴엔 과함 → 참고만 |
| **Discord** | 커뮤니티 | Ash/Onyx, 사람=원 / 서버=스쿼클 | 형태 언어만 |
| **Ledgerline / 편집 데스크** | 편집·운영 | 종이+헤어라인 | 크림 신문형은 AI 클리셰라 **의도적 회피** |
