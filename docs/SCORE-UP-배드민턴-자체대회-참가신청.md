## 1. 한 줄

클럽(모임) 회원이 가입된 상태에서, 모임장이 **월 1회 자체대회**를 열고 멤버에게 **참가신청**을 받아 명단·대진·보드까지 이어 간다.  
경기 기본은 **1판**, 목표점수·판수는 대회/경기에서 커스텀 가능.

---

## 2. 왜 필요한가

기존 mock: 자체대회 = 기존 「대회 만들기」와 **연결 필드 없음** (모임 기획 §21.1).  
현장: 회원가입 → 멤버 참가신청 → 대진 → 스코어. 이 연결이 없으면 총무가 엑셀·카톡으로 명단을 다시 만든다.

---

## 3. 핵심 플로우

```text
모임 홈
 → [자체대회 열기]
 → 대회 기본 정보 (이름·날짜·장소·종목=배드민턴 고정)
 → 경기 규칙 기본값 (목표점수 21, 판수=1판, 변경 가능)
 → 참가 모집 열기 (멤버에게 신청 받기)
 → 멤버: 참가 신청 / 취소 (마감 전)
 → 모임장: 신청 목록 승인·거절 · 외부 참가자 추가
 → 참가 확정 명단으로 대진 생성
 → 경기별 보드 (터치 +1)
 → 결과 → 대진 반영 · (선택) 모임 전적 요약
```

---

## 4. 자체대회 열기 (모임 → Competition)

| 필드 | 규칙 |
| --- | --- |
| 연결 | `Competition.clubId` = 현재 모임 id (**신규 필드**) |
| 종목 | `badminton` 고정 (이 MVP) |
| 이름 | 예: `9월 자체대회` |
| 일시·장소 | 필수 |
| 모집 마감 | 일시. 지나면 신규 신청 불가(운영자 수동 추가는 가능) |
| 참가 대상 | 기본 **모임 멤버** + (옵션) 외부 참가 허용 |

### 4.1 경기 규칙 기본값 (대회 단위)

| 항목 | 기본 | 옵션 |
| --- | --- | --- |
| 목표점수 | 21 | 25, 커스텀 11~30 |
| **판수** | **1판** | 3판 2선, 5판 3선, 커스텀 선승 |
| 형식 | 단식 / 복식 / 혼합(종목 내 이벤트 여러 개 later) | MVP는 대회당 **단식 또는 복식 하나** |
| 대진 | 토너먼트 (기본) | 리그는 later |

보드 UX 스펙의 자체대회 기본과 동일. 개별 경기는 보드 입장 전 override 가능.

## 5. 멤버 참가신청

| 역할 | 할 수 있는 일 |
| --- | --- |
| 멤버 | 모집 중: 참가 신청 / 취소. 복식이면 파트너 희망(선택, 1차는 메모만) |
| 모임장·운영 | 신청 목록 보기, 승인/거절, 마감, 수동으로 멤버 추가 |
| 비멤버 | 이 절 아님 → 외부 참가자 문서 |

상태:

```text
open → applied → accepted | rejected
open → closed (마감)
accepted → withdrawn (마감 전 본인 철회, 운영자 확인 optional)
```

신청 UI:
- 모임 상세 · 자체대회 카드 · 푸시/딥링크(계정 최소 후)
- 카피: 「9월 자체대회에 참가할까요?」 [참가 신청]

승인 후 **참가 확정 명단** = 대진 입력 소스.  
기존 `/competition/[id]/roster`를 배드민턴용으로 확장: 팀 카드 대신 **선수(단식) / 복식 조** 목록. 탁구 참가-상세와 유사.

---

## 6. 대진 · 보드

1. 확정 인원 ≥2 (단식) 또는 복식 조 ≥2
2. 「대진 만들기」 → 기존 bracket 흐름
3. 경기 탭 → 보드. 규칙 기본값 = 대회 설정(1판·21점 등)
4. 종료 시 승자 대진 반영

한 회차 픽업「한 판 열기」와 **섞지 않음**. 자체대회는 Competition, 주간 픽업은 Session.

---

## 7. 화면·라우트 (제안)

| 경로 | 역할 |
| --- | --- |
| `/club/[id]` | [자체대회 열기] CTA |
| `/club/[id]/competitions/new` | 만들기 위저드 (규칙 포함) |
| `/competition/[id]` | 개요 · 모집 상태 · 참가 관리 |
| `/competition/[id]/entries` | 신청·승인 목록 (신규) |
| `/competition/[id]/roster` | 확정 명단 (기존 확장) |
| `/competition/[id]/bracket` | 대진 |
| `/match/[id]/badminton` | 보드 |

---

## 8. 계정 전제

참가신청은 **누가 신청했는지**가 필요하므로 계정 최소(초대·동일인 식별)가 선행 또는 동시 P0.  
기기 로그인만으로는 멤버 다기기 투표·신청을 증명하기 어렵다.

---

## 9. 넣지 않음

- 참가비·셔틀비 결제
- 남복/여복/혼복 자동 대진
- A~D조 자동 시드 (급수는 초중상 유지. 시드는 수동)
- 교류전 상대 클럽 연동
- `이 회차를 대회로` 변환 (Session→Competition 일괄 변환)

---

## 10. 검수 시나리오

1. 모임장: 자체대회 생성, 판수=1판·21점, 모집 오픈
2. 멤버 8명 신청 → 7명 승인
3. 외부 2명 수동 추가 (OCR 전)
4. 대진 생성 → 준결승·결승 보드 1판씩 완료
5. 판수를 3판2선으로 바꾼 대회 1회 추가 스모크
