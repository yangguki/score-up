## 1. 한 줄

가로 보드에서 **좌/우 큰 영역을 터치하면 +1**. 목표점수는 **21 / 25 / 커스텀**, 판수(세트)는 **커스텀**. 자체대회 기본은 **1판 승부**이나 대회·경기마다 바꿀 수 있다.

---

## 2. 득점 입력

| 규칙 | 내용 |
| --- | --- |
| 기본 동작 | 홈(왼쪽) / 어웨이(오른쪽) **터치존 탭 = 그쪽 +1** |
| 터치존 | 점수 숫자·이름 영역을 포함한 **반쪽 화면 전체** (작은 +1 버튼만 두지 않음. 하단 독에 +1을 중복하지 않음) |
| 활성 | `in_progress` 일 때만. 시작 전·일시정지·확인 대기면 터치 비활성 |
| 피드백 | 탭 즉시 점수 반영 + 짧은 하이라이트. 진동은 기기 지원 시 optional |
| 실행 취소 | 상단 또는 하단 **되돌리기** 1회분(직전 득점). 세트 확정 후에는 관리자만 정정 |
| 서브 | 동호회 기본: **득점자가 서브**. 서브 **표시**만. `1/2` 카운트 UI 없음. 오기록은 되돌리기 |
| 금지 | +2/+3, 파울, 시계, 복잡한 위자드 |

---

## 3. 목표점수 (포인트)

| 프리셋 | 설명 |
| --- | --- |
| **21** | 동호회 기본 (룰 명세서 4-B) |
| **25** | 클럽·자체대회에서 자주 쓰는 대안 |
| **커스텀** | 11~30 정수. 범위 밖이면 「11~30으로 입력하세요.」 |

- 경기 **시작 전** 설정 시트에서 고름.
- 진행 중 변경은 **일시정지 + 운영자 확인** 후에만 (일반 캐논 「시작 후 룰 변경 금지」의 배드민턴 MVP 예외).
- 듀스: 기본 **2점 차** 필요. 커스텀 시에도 `needMargin=2` 유지. cap 옵션·승점 차 선택 UI는 later.

---

## 4. 판수 (세트)

| 항목 | 내용 |
| --- | --- |
| 의미 | best-of-N 또는 고정 N판 중 **「몇 판을 먼저 / 몇 판을 할지」** |
| UI 표현 | `판수` + 프리셋 + 커스텀 |
| 프리셋 | **1판** · **3판 2선**(기본, 동호회) · **5판 3선** |
| 커스텀 | `선승 판수` S (1~5) → 실질 best-of-(2S-1). 예: S=2 → 3판 2선 |
| 자체대회 기본 | 아래 §5 — **1판** |
| 모임 한 판 / 친선 기본 | **3판 2선**, 목표 **21** |
| 진행 중 하한 | 이미 이긴 세트보다 선승을 낮출 수 없음 |

시작 전 시트 예시:

```
목표점수   ( ) 21  ( ) 25  ( ) 직접 입력 [__]
판수       ( ) 1판  (•) 3판 2선  ( ) 5판 3선  ( ) 직접 [선승 __]
[경기 시작]
```

### 4.1 룰 시트 진입

| 시점 | UI |
| --- | --- |
| 경기 시작 전 | 오버레이 시트에 현재 룰 요약 + 위 선택. 확정은 **경기 시작** |
| 일시정지 | 하단 독 **룰 변경**. 판수·목표점수만 고르고 **적용** (승점 차 없음) |

---

## 5. 자체대회 vs 모임·친선 기본값

| 컨텍스트 | 목표점수 기본 | 판수 기본 | 변경 |
| --- | --- | --- | --- |
| 모임 회차 한 판 | 21 | 3판 2선 | 경기마다 가능 |
| 친선 | 21 | 3판 2선 | 가능 |
| **자체대회 경기** | 21 | **1판** | 대회 설정에서 일괄 + 경기별 override |

자체대회는 시간·코트 회전을 위해 **1판(한 세트 승부)** 이 기본이다.  
대회 만들기/자체대회 설정에:

- `경기 판수 기본`: 1판 / 3판 2선 / 5판 3선 / 커스텀
- `목표점수 기본`: 21 / 25 / 커스텀

개별 Match는 보드 입장 전 시트에서 override 가능(운영자만).

## 6. 화면 레이아웃 (가로)

셸은 농구 Arena(좌우 색면). 보드는 **가로만**. 세로는 「가로로 돌려 주세요」.

```
┌──────────────────────────────────────────┐
│ 세트 n/N   홈세트 : 어웨이세트    [되돌리기] │
├────────────────────┬─────────────────────┤
│                    │                     │
│     HOME 이름      │     AWAY 이름       │
│        18          │         16          │  ← 큰 숫자
│   (탭하면 +1)      │    (탭하면 +1)      │
│                    │                     │
├────────────────────┴─────────────────────┤
│ 서브 ●홈    목표 21 · 1판/3판2선   [일시정지]│
└──────────────────────────────────────────┘
```

보드에 둘 것: 양쪽 팀명(복식이면 슬래시), 현재 세트 점수, 세트 스코어, 세트 이력, 서브권 표시, 되돌리기, 듀스/세트포인트 알림.

- 복식: 이름은 `A / B` 한 줄. 위치·서브 순서 강제 UI 없음 (1차).
- 결승 세트 **11점**에서 엔드 교대 알림만 (룰 명세서 4-B).
- 세트 종료 시: 「홈 세트 획득」확인 → 다음 세트 또는 경기 종료.
- 경기 종료: 점수·세트 요약 → 모임 전적 / 대진 반영.

## 7. 데이터 (예약)

```text
Match.rules.targetPoints     21 | 25 | number (11..30)
Match.rules.setsToWin        1 | 2 | 3 | …   // 선승 판수
Match.rules.needMargin       2
Match.context                session | friendly | competition
```

프리셋 매핑: 1판 → setsToWin=1 / 3판2선 → 2 / 5판3선 → 3.

구현 파일 경계는 Badminton agent (`packages/domain` 프리셋, 탁구 공유 스냅샷, `table-tennis-board` 공유 셸).

## 8. 넣지 않음 (이 스펙 밖)

- 하단 독의 작은 +1 중복, 서브 변경 버튼(표시만)
- 멀티코트 TV 현황판
- 복식 포지션·코트 사이드 강제
- 서브 카운트 1/2 UI
- 렛 이벤트
- 파울/카드/시계/타임아웃
- 세로 보드 (보드는 가로만 유지. 안내는 기존과 동일)
- 승점 차 선택 UI (margin=2 고정)
