## 1. 잠근 것 (이 와이어가 지키는 것)

탭 3개, 홈 `내 모임` 섹션, 랭킹=회차+급수 경기·멤버(급수별), 게스트=이름만, 미정=매칭 제외, 가입=초대+승인, 기본=5v5, **8~9명이면 4대4로 나누기**, **월 정기(N번째 요일 / D일 1~28)**, 급수=초급/중급/상급, 모임장=기록원, 새 보드 없음. 3x3·자동 포맷 전환·공휴일 자동 스킵·ELO 없음.

## 3. 진입

```text
홈 `내 모임` 카드 ──▶ /club/[id]
홈 (이후) 오늘 회차 카드 ──▶ /club/[id]/sessions/[sid]
설정 또는 개요 `모임 만들기` ──▶ /club/new
초대 링크 ──▶ /club/join/[token]
팀 나누기 확정 ──▶ 출전 명단 (농구)
한 판 열기 확정 ──▶ 배드민턴 보드 (lineup 스킵)
```

지금 H1 홈에 `내 모임`을 그린다. 필드는 5장.

## 4. 화면별 와이어

### 4.1 모임 만들기 `/club/new`

한 화면. 대회 만들기 4단계와 섞지 않는다.

```text
모임 만들기                         닫기

종목
  [ 농구 ]   [ 배드민턴 ]   [ 배구 비활성 ]   [ 탁구 비활성 ]

이름
  [ 주말 농구 모임        ]

기본 장소 (선택)
  [ 시민체육관 3코트       ]

[ 모임 만들기 ]
```

완료 → 개요. 만든 사람이 모임장. 다음 할 일 카피: “멤버를 초대하고 첫 회차를 만드세요.”

잠금: 종목 미선택, 이름 공백.

### 4.2 가입 요청 `/club/join/[token]`

비멤버. 만료·잘못된 토큰은 “링크가 유효하지 않습니다. 모임장에게 다시 받으세요.”

```text
주말 농구 모임
농구 · 멤버 12

이 모임에 가입하려면 모임장 승인이 필요합니다.

[ 가입 요청 ]
```

요청 후: “승인을 기다리는 중입니다.” 버튼 비활성.  
이미 멤버면 개요로 보냄.  
모임장/운영이 같은 링크를 열면 멤버 화면의 초대 섹션.

### 4.3 개요 `/club/[id]`

```text
다음 회차  8/29 토 14:00  시민체육관
내 투표    참석

[ 회차 열기 ]     [ 멤버 ]

다가오는 회차
  8/29 토 14:00  투표 중  참석 8 · 미정 2
  9/5  토 14:00  투표 중  참석 3

[ 랭킹 ]  [ 전적 ]
[ 도전 ]  [ 결과 넣기 ]
```

- 모임장/운영: `회차 만들기`가 `회차 열기` 옆에 보임 (또는 회차 목록 상단)
- 멤버: 다음 회차 탭 → 회차 상세. 투표는 상세에서
- 빈 회차: “다음 회차를 만들면 참석 투표를 받을 수 있습니다.” + 모임장만 `회차 만들기`
- 가입 대기 중 비멤버는 이 화면 대신 4.2

### 4.5 회차 만들기 `/club/[id]/sessions/new`

```text
← 회차 만들기

○ 한 번만
○ 매주 반복
○ 매달 반복

날짜 · 시각
  2026-08-29  14:00

매달이면
  ○ 매달 N번째 요일     ○ 매달 n일
  [ 첫째 ] [ 둘째 ] [ 셋째 ] [ 넷째 ] [ 마지막 ]
  [ 일 ] [ 월 ] … [ 토 ]          ← N번째일 때. 기본은 날짜의 요일
  일자 [ 15 ]                    ← 매달 n일. 1~28만

장소
  [ 시민체육관 3코트 ]

투표 마감
  시작 2시간 전

반복이면: 앞 8회 회차가 투표 중으로 만들어집니다.

[ 회차 만들기 ]
```

매주: 시작 날짜부터 7일 간격 8회.  
매달 N번째: 시작일 이후 해당 N번째 요일 8회.  
매달 D일: 시작일 이후 그 일자 8회. 29~31 잠금. “말일은 28일로 두세요.”  
같은 날짜의 미취소 회차가 있으면 건너뜀. 0회면 “이미 같은 날짜 회차가 있습니다.”  
만든 직후 첫 회차 상세로. 모임 규칙 필드도 갱신.

### 4.6 회차 상세 `/club/[id]/sessions/[sid]` — 메인

**목적:** 멤버는 투표, 운영자는 마감·게스트·팀 나누기. 출전 n과 참석을 한 화면에 섞지 않는다.

#### 투표 중 `voting`

```text
← 8/29 토 14:00              더보기
시민체육관 3코트 · 마감 12:00
상태  투표 중

내 응답
  [ 참석 ]  [ 불참 ]  [ 미정 ]     ← 하나 선택. 마감 전 변경 가능

참석 8   불참 2   미정 3   없음 1

참석
  김민수  박지훈  …
미정
  한지호  …
불참 · 없음  (접힘)

모임장만
  [ 투표 마감 ]
```

투표 중 한 줄 안내: 농구 “마감 후 참석 10명이면 5대5, 8~9명이면 4대4로 나눌 수 있습니다.” 배드민턴 “마감 후 단식 2명 또는 복식 4명이면 한 판을 열 수 있습니다.”

더보기(모임장/운영): 회차 취소, 마감 시각 수정(`voting`만).

마감 확인: “이제부터 멤버는 투표를 바꿀 수 없습니다. 마감할까요?”

#### 확정 중 `confirming`

```text
← 8/29 토 14:00
상태  인원 확정
참석 8  (매칭 후보) · 미정 3 (후보 아님)

매칭 후보 8
  김민수  [ 빼기 ]     ← 운영자: 참석 취소
  게스트 민수친구  [ 빼기 ]

미정 · 없음
  한지호  [ 참석으로 ]  ← 운영자만. 하면 후보에 합류

[ 게스트 이름 추가 ]

후보 10명 이상
  [ 팀 나누기 ]

후보 8~9명
  [ 팀 나누기 ]                 ← 잠금
  5대5는 참석 10명이 필요합니다. 게스트를 추가하거나 4대4로 나누세요.
  [ 4대4로 나누기 ]             ← 활성. 누르면 format=4v4, split로

후보 8명 미만
  [ 팀 나누기 ]                 ← 잠금
  [ 4대4로 나누기 ]             ← 잠금
  4대4는 참석 8명이 필요합니다. 게스트를 추가하세요.
```

멤버는 목록 조회만. 투표 버튼 없음.  
`[ 참석으로 ]`는 미정·없음·불참에 모두 가능. 이력 남김.

배드민턴 회차 confirming은 5v5/4v4 대신 **단식 / 복식 + 한 판 열기**. 카피·미달은 §21.6·§4.7b. 자동 제안 없음.

#### 팀 확정 `matched`

```text
상태  팀 확정

A  김민수 박지훈 … (n)
B  최유진 … (n)
대기  한지호  게스트 민수친구

내 팀  A
4v4이면 한 줄: 4대4 · 출전 팀당 4명

모임장  [ 출전 확인 ]  → 기존 lineup
         [ 다시 나누기 ]  확인 후 confirming 또는 split
멤버    보드 진입 없음
```

#### 경기 중 / 종료 / 취소

- `in_play`: 그날 Match 카드 (점수·이어하기는 모임장만 보드). 라운드 자리 없음, 상대는 A vs B
- `completed`: 최종 점수 + `랭킹에 반영됨` (게스트 한 줄 도움말만)
- `cancelled`: “이 회차는 취소되었습니다.” 전적 없음

### 4.7 팀 나누기 `/club/[id]/sessions/[sid]/split`

수동 + 자동 제안. 출전 칸 수는 회차 `format`.

```text
← 팀 나누기
후보 n명 · 출전 5+5 (또는 4+4) · 나머지 대기

[ 자동 제안 ]  [ 승률 밸런스 ]

A 팀                    B 팀
  김민수 [ → ]            [ ← ] 최유진
  …                       …
대기
  한지호  게스트 민수친구

A n · B n 이어야 [ 매칭 확정 ] 활성
```

규칙

- 후보 = `going` + 게스트. `maybe` 없음
- 5v5: A·B 각 5. 4v4: A·B 각 4. 초과분은 대기
- 게스트도 A/B/대기 가능. 랭킹에는 안 쌓임
- 확정 → Match 1개 생성 (홈=A, 어웨이=B, `sessionId`) → `matched` → 출전 명단
- 4v4 Match는 `rules.starters = 4`. 대회 프리셋 5는 바꾸지 않음
- 출전 명단의 선발 기본값 = 나눈 n명. 벤치 = 대기
- 이 화면에서 포맷을 바꾸지 않음. 돌아가서 5v5 팀 나누기 / 4대4로 나누기를 다시 고름

확정 확인 5v5: “팀을 확정하고 경기를 만들까요? 이후 변경은 다시 나누기입니다.”  
확정 확인 4v4: “팀을 확정하고 경기를 만들까요? 출전은 팀당 4명입니다. 이후 변경은 다시 나누기입니다.”

5v5인데 후보 10명 미만, 또는 4v4인데 8명 미만이면 이 화면에 못 들어옴 (상세에서 잠금).

### 4.7b 배드민턴 한 판 `/club/[id]/sessions/[sid]/bout`

농구 `split`과 섞지 않음. 자동 제안 없음. 배드민턴이 아니면 split으로 보냄.

```text
← 한 판 열기
복식 · 후보 n명 · 출전 2+2 · 나머지 대기

홈                         어웨이
  김민수 [ → ]               [ ← ] 이서연
대기
  [ 홈 ] 박지훈 [ 어웨이 ]

[ 한 판 열기 ]
```

- 단식: 양쪽 1. 복식: 양쪽 2. 초과분은 대기
- 확정 → Match 1개 (`sessionId`, `sportId=badminton`) → 보드. 출전 명단 없음
- 복식 이름은 슬래시. 위치·서브 순서 강제 없음
- 이 화면에서 포맷을 바꾸지 않음. 회차 상세의 단식/복식을 다시 고름

확정 확인: “한 판을 만들고 보드로 갈까요?”

단식 후보 2 미만, 복식 4 미만이면 이 화면에 못 들어옴.

### 4.9 전적 `/club/[id]/records`

회차 경기 카드 최신순 + 급수 경기 카드. 대회·친선 없음.  
회차 탭 → 기존 결과 화면. 급수 경기는 보드 없음.

### 4.10 모임 설정 `/club/[id]/settings`

모임장: 이름, 기본 장소, 시즌 시작·끝, **정기 규칙 한 줄**(매주 / 매달 N번째 요일 / 매달 D일), 해체(확인).  
규칙 저장은 모임 필드만. **이미 만든 회차는 그대로.** “새 회차는 회차 만들기에서 만듭니다.”  
가입 방식 토글 **없음**. 기록원 지정 **없음**. 공휴일 달력 **없음**.

## 5. 홈 `내 모임`

섹션 위치: `내 대회` **아래**. 빈 홈(대회 0·모임 0) 또는 모임 0이면 섹션 숨김.

카드 (2~5개, `completed` 모임 제외)

| 줄 | 내용 |
| --- | --- |
| 1 | 모임명 + 필 `농구` |
| 2 | 다음 회차 `{날짜 시각}` 또는 `다음 회차 없음` |
| 3 | 내 투표 `참석` / `불참` / `미정` / `없음` — 다음 회차가 `voting`일 때만. 그 외 줄 생략 |

탭 → `/club/[id]`. 투표는 홈에서 하지 않음 (상세에서).
